## O1 — double tribute, equal-power tribute cards
**Verdict: payer→receiver is NOT decided by card power at all; tie-break leader ≠ "Banker's upstream seat".**
`Finish.settlement()` (types.py L300-316) fixes `tri_ship = [(order[-1], (order[-1]-1)%4), (order[-2], (order[-2]-1)%4)]` at round-end, *before* any tribute card is chosen. Because the two losers occupy the seats adjacent to Banker, `(loser_seat-1)%4` structurally resolves to either Banker or Follower — so payer/receiver is seat-geometry, not card power. `table.py` `tribute()` L300-319 only uses `cmp_rank` to set `first_play` (who leads):
```
if cmp_result == 1: self.settlement.first_play = tri_pos_b
elif cmp_result == -1: self.settlement.first_play = tri_pos_a
else: self.settlement.first_play = self.settlement.fourth   # tie
```
On a tie the leader is set to `self.settlement.fourth` — the **previous round's Dweller (4th-place finisher)**, not "Banker's upstream seat" as RULES.md O1 states. These need not be the same seat.

## O2 — back-tribute legality
**Verdict: natural rank 2–10 only, AND level cards of any suit excluded. No fallback exists in source.**
`Player.less_than_ten` (types.py L232-234):
```python
def less_than_ten(self, current_rank):
    cards = [str(c) for c in self.hand_cards if c.digital & 0x00FF <= 10 and c.rank != current_rank]
    return [["back", "back", [k]] for k in Counter(cards).keys()]
```
`digital & 0xFF <= 10` = natural ranks 2..T; `c.rank != current_rank` drops **all four suits** of the level rank, not just the wild heart. Matches RULES.md O2. No "any lowest-power card" fallback code exists anywhere in `table.py`/`types.py`; if `cards` is empty, `action_list` is empty (not determined by source what the jar/client would do with an empty list).

## O4 — passing level A
**Verdict: partially matches, two contradictions found.**
`table.py` L258-271, inside `play()` after a round ends with `self.__rank == 14` (round level A):
- Winner on the owning team AND partner ≠ Dweller → `one_times_over` (match win). Matches RULES.md 8.5.
- Winner on the owning team AND partner == Dweller → `stuck_at_ace` (L500-522): failure counter increments; **only incremented here**.
- Winner NOT on the owning team → ownership simply passes (`belongs_to = first_pos`, `enter_tribute_stage`), **stuck_times is never touched**. This contradicts RULES.md 8.7 ("Every owned round at level A that does not pass counts as one failure... whether the owner lost the round or won it with Banker and Dweller") — a plain loss registers **no** failure in source.
- Reset threshold: `stuck_at_ace` L507 `if self.players[first_pos].stuck_times > 3:` — since this check runs *after* incrementing, the reset to level 2 (`start_new_episode_back_2`, resets both partners' `rank`/`stuck_times`) fires on the **4th** consecutive qualifying failure, not the 3rd as RULES.md O4/`a_fail_limit = 3` states.
"Both teams at A" case: no explicit rank-equality check exists; a non-owning team that wins a round at A is simply promoted via `update_rank` (types.py L173-175, `min(rank+inc, 14)`), which naturally caps at A — this matches T-FLOW-13/rule 8.6 behavior by construction, not by an explicit comparison.

## O5 — order of the last two after a double win
**Verdict: ascending seat index 0→3, NOT "next(Follower)".**
`table.py` L252-255:
```python
if self.settlement.episode_over():
    for i in range(4):
        if len(self.players[i].hand_cards) > 0:
            self.settlement.add(i)
```
Counter-example: Banker=3, Follower=1 (double win), remaining seats {0,2}. Ascending gives `[0,2]`; "next(Follower)" (skip finished seats starting at seat 2) would give `[2,0]`. These differ, so RULES.md's stated O5 resolution does not match source.

## Tribute card selection
**Verdict: highest power, wild (heart level) cards de-prioritized where a natural alternative ties.**
`Player.max_cards` (types.py L213-230): forces a lone `HR` or lone `SB` if it's the hand's top card; otherwise collects all cards tied with the top-power card, with an `avoid_h` branch that drops the `H`-suited level card from the offered set when a non-heart card of the same power exists. Matches RULES.md 9.3's "ignoring wild cards" framing.

## Anti-tribute
**Verdict: matches RULES.md.**
`act_tribute` (table.py L161-208): single-loser case (`fourth_anti`) fires when `players[fourth].red_joker_num == 2` (holds both `HR`s, since `red_joker_num` — types.py L207-211 — actually counts red jokers held, i.e. up to 2 `HR` copies in this two-deck game). Double-loser case additionally fires anti-tribute when third and fourth each hold exactly one `HR` (`fourth_anti, third_anti = True, True` at L172-173), or either alone holds both. Leader after anti-tribute is always `self.settlement.first` (L176/195), i.e. the Banker — matches RULES.md 9.1.1/9.2.1.

## Level gain
**Verdict: matches.** `Finish.settlement()` (types.py L300-316): `inc=3` if 2nd place is Banker's partner (double win), `inc=2` if 3rd place is, else `inc=1`. Cap at A: `Player.update_rank` (types.py L173-175) `self.rank = min(self.rank + inc, 14)` (14 = `A`).
