# 手牌融合与归一化分离验证（2026-10-16）

状态：**离线完成。当前证据支持 query 变化先遮蔽历史线索，逐行减均值使剩余线性可读增益进一步变弱；不支持“归一化独自擦掉大部分历史”。** 没有训练、生产行为改动或后继任务。

## 范围与固定设计

承接[分层检查](qknorm-history-stages-2026-10-16.md)。仍使用同一 control/qk-both
与 norm16 端点、同一旧模型对手池和公开信息边界。只读已保存的 1,024 个第
4 局决策摘要，以及上次等长历史替换的 707 个同局面样本，不再打比赛。

两个问题分开测：

1. **跨局有用线索可读性**：复用前 8 waves 每端点 256 场校准、后 8 waves
   256 场核验，保持 128 个测试 seed 簇与独立 256 道相同牌公开首出题。固定
   闭式 ridge，正则 N，统计缩放下限 .01，另预定 1e−6 灵敏度对照；不更新
   actor、critic、辅助头或任何神经网络，不创建优化器。
2. **同局面真实内容变化的几何去向**：重算原先 357/350 个等长固定元数据
   替换，完全保留当前手牌、候选、公开当前局、位置和真实 query。沿真实
   reader→query 加法→attention_norm 观察，不依赖线性探针是否好用。

完整事前方案见 `.work/qknorm-fusion-isolation-2026-10-16/protocol.json`。

### 因子与恢复对照

- query 因子：真实当前 query，或固定为**仅由校准集**计算的均值。后者只
  在融合加法处代换；实际 reader 已经按真实 query 算好，保持不变。这隔离
  加法中的手牌分支变化，不把它和上游 attention 读取变化混在一起。
- 归一化因子：无归一化、仅逐行减均值、再除逐行标准差、最后乘加已学习的
  gamma/beta。全部使用原 LayerNorm 的 epsilon。
- 辅助对照：标准化表示附带原均值、尺度或两者；也用保存的两个统计量精确
  反归一化，再减 query，检验是否能恢复原 reader。
- 每个条件独立校准同一固定统计读数；不挑超参数、不接回 actor。FULL 与
  ROUND 都通过同一条件，报告独立问题误差改善及 seed×问题交叉 bootstrap
  95% 描述区间，10,000 次，seed 16102731/32。
- 所有多条件结果均是探索性机制证据，不是多重检验校正后的架构验收，更不
  是动作正确性或胜率验证。

## 1. 当前手牌分支的变化确实会遮蔽可读线索

下表是 FULL 相对 ROUND 的独立公开首出题 Brier 改善，正数更好；不是胜率。

| 表示／条件 | control 改善 [95% CI] | norm16 改善 [95% CI] |
|---|---:|---:|
| reader 本身 | +0.009649 [+0.005337, +0.014193] | +0.008167 [+0.003545, +0.012987] |
| 加真实 query | +0.003579 [+0.000801, +0.006440] | +0.003548 [+0.000585, +0.006509] |
| 加固定均值 query | +0.009649 [+0.005337, +0.014193] | +0.008167 [+0.003545, +0.012987] |

移除跨样本 query 变化后，加法不再损害这套读数，符合“历史仍在混合向量中，
但当前分支变化让固定统计读数更难从中提取”的解释。相比真实 query，固定
query 的改善之差分别为 +0.006069 [+0.003242, +0.009072]、
+0.004618 [+0.001633, +0.007778]。

固定 query 的效果不代表 actor 在真实牌局中可以放弃手牌输入。加法本身也
不是不可逆删除：如果另外知道 query，就能从和中减回 reader。当前路径没有
把 query/reader 作为两路独立表示交给后续策略，而是先相加再变换。

## 2. 额外变弱主要发生在“减均值”，不是后面的缩放或 affine

真实 query 条件下：

| 归一化进度 | control 改善 [95% CI] | norm16 改善 [95% CI] |
|---|---:|---:|
| 尚未归一化，query＋reader | +0.003579 [+0.000801, +0.006440] | +0.003548 [+0.000585, +0.006509] |
| 只减逐行均值 | −0.000293 [−0.000927, +0.000322] | −0.000495 [−0.001148, +0.000147] |
| 再除逐行标准差 | −0.000436 [−0.001116, +0.000228] | −0.000608 [−0.001284, +0.000059] |
| 再乘加 gamma/beta（原 LN） | −0.000433 [−0.001113, +0.000231] | −0.000609 [−0.001286, +0.000060] |

配对“损失了多少读数增益”的比较：

- 减均值：control +0.003872 [+0.001262, +0.006555]，norm16
  +0.004044 [+0.001351, +0.006799]。
- 除尺度：+0.000144 [−0.000028, +0.000320]、
  +0.000112 [−0.000056, +0.000290]，未确立额外影响。
- gamma/beta：约 −0.000004 / +0.000001，区间跨零；没有发现其造成主要差别。
  两端点 gamma 绝对值最小为 0.05324/0.06135，并非把某些通道设成精确零。

这里是特定线性读数的可读性变化；区间跨零不证明无信息，也不能把改善之比
叫作“传递了百分之多少有用信息”。

## 3. 两者存在交互，不能把归一化独立定罪

固定 query 后，即使仍使用原 learned LayerNorm，历史预测优势也恢复：

| 统计读数缩放下限 | control 原 LN 改善 | norm16 原 LN 改善 |
|---|---:|---:|
| 原定 .01 | +0.006203 [+0.003177, +0.009344] | +0.005177 [+0.001971, +0.008528] |
| 预定灵敏度对照 1e−6 | +0.009197 [+0.005036, +0.013603] | +0.007975 [+0.003485, +0.012655] |

小下限让固定 query 的细小特征变化也被统计读数平等衡量；这**只改分析的缩放**，
不是给模型放大历史。真实 query 下从 .01 改为 1e−6，主要结论不变。

说明“使用 LayerNorm 必然消灭历史”不符合这些对照。真实 query 变化与中心化
共同决定了这条细弱线索是否容易被后续固定读数利用，不能从这几项差值拆成
两个互相独立的原因比例。

给原归一化表示简单追加原均值／尺度作为额外线性特征，并没有恢复可靠增益；
只有执行正确的反变换并减掉 query，才恢复到 reader 的原有结果。这也提示：
“多提供两个统计数就能修好策略”并没有得到本次支持。

## 4. 归一化没有几何上抹掉绝大多数内容变化

对原先等长替换的 707 个局面重算：同一手牌、同一 query、同一当前局和位置，
只换旧公开历史 token。把 reader 改变量投影到 LayerNorm 的均值方向、径向
和剩余切向；三者是正交的平方向量能量分解。

| 几何量（逐行比例的平均） | control，357 行 | norm16，350 行 |
|---|---:|---:|
| 均值方向 | 7.32% | 7.96% |
| 径向 | 0.58% | 0.64% |
| 剩余切向 | 92.10% | 91.39% |
| 真实有限变化扣除整体单位缩放后仍保留的能量 | 92.03% | 91.33% |

直接除去整体尺度后，大多数扰动仍然存在。归一化前的整体标准差中位数约
88.64/88.71，因此归一化输出绝对数值变小不等同于内容被删除。

**向量能量不是预测价值。** 少数方向可能承载了这套统计读数最容易利用的
线索，多数剩余变化也可能无关紧要；这里不能说“保留了 92% 的有用信息”。
但这个检查足以反对“归一化擦掉了绝大多数历史内容变化”的简单解释。

707 行的原历史 KV logp 门槛全部通过，最大误差 3.0518e−5/3.8147e−5；
等长替换 TV 重现到 <2e−5，全部首选变化与上次一致（各 2 次）。原生 LN 与
双精度拆解最大误差 3.0710e−6/2.9975e−6。解析方向分解与有限变化相容，
线性化误差相对原始 reader delta 的中位数 0.44%/0.46%。

## 人话结论

**不是二选一：手牌那一路先把历史线索混得难找，“减均值”又让剩下的线索
更难利用。两个端点都一样。** 固定手牌分支的变化后，线索即使经过原来的
归一化也能重新读清楚，所以不能把问题全归到归一化头上。

当前更支持“历史信息的表达和融合方式不利于后续使用”，而不是“历史编码器
没记住”或“LayerNorm 算坏了”。这仍是离线可读性与内容扰动证据，不证明
信息彻底消失、模型理应改变动作、删掉归一化就能多赢，或 norm16 已修复问题。
