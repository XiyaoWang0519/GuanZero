Eight deals were excluded because a leg had `their_choice_missing`:
1238, 1739, 1824, 1865, 2121, 3309, 3669, 3932. All failed-leg records are
retained. Divergence counts are `our_candidate_unmatched=213`,
`their_choice_missing=8`, `their_choice_reading=42`. This remains an adapter
evaluation with rule/candidate mismatches, not a clean engine-parity result.

The paired comparison with the existing u86800 result uses 3,989 jointly
scored deals, resampling whole deals (5,000 bootstrap samples, seed 0).
u99200 minus u86800 is **+0.09087 net levels per round**, 95% bootstrap
interval **[+0.04337, +0.13788]**. On these common deals the means are
−0.25633 and −0.34720. The round-win-rate change is +0.8273 percentage points,
95% interval [−0.2883, +1.9682] pp; it does not establish a win-rate gain.
The union of excluded deals is 11. Assigning their paired score differences
any value in [−6, +6] bounds the all-deal mean difference at
[+0.074125, +0.107125]; this is a missing-score bound, not a confidence interval.

This sample supports a net-level improvement over u86800, while u99200 still
trails DanLM. It does not measure full-match strength, history dependence,
search strength, or performance of a later remote checkpoint. The reused deal
set provides a paired comparison, not a new independent holdout.
