# 前三局公开出牌能否预测后续行为（2026-10-16）

状态：**已完成；这套公开统计未发现前三局能稳定改善后续行为预测。真实比赛和同牌题的主比较均未见改善，直接沿用前三局偏差的探索性规则反而变差。** 本次只查预测信息，不测试如何
利用信息多赢、不继续 PPO 或训练任何神经网络、不改生产实现或 checkpoint。

## 问题与固定设计

承接[完整比赛 FULL／ROUND 消融](qknorm-match-ablation-2026-10-16.md)：上次
胜率区间覆盖零，既不能断言模型不会用历史，也不能断言历史无用。本轮问一个更窄
的问题：前三局已经公开的出牌，能否帮助预测同一冻结对手此后的公开行为？

对手仍是共同 parent 的 u94482、u94484、u94486、u94488 四个冻结 Transformer；
己方是上一轮 control / norm16 两个冻结端点。此前保存的是逐场结果、首局行动
摘要，没有逐手日志。因此**复跑此前 1,024 场 FULL 比赛**补记公开事件，不把复跑
当成新增棋力样本；每场的所有原有记录必须与原结果完全相同。

- 16 wave × 32 slot × 2 端点 = 1,024 场。wave 00–07 的 512 场仅作参考计数，
  wave 08–15 的 512 场作检验。整场和同 seed 的两次队伍互换、两个己方端点一起
  分组，不把同一比赛的出牌拆到参考组和检验组。
- 只看对手两席；前三局的公开行为固定为历史，从第四局开始预测。四类结果：
  过牌、单张、炸弹类（含同花顺、王炸）、其他。自动过牌也计入；不读 `forced`
  标志，所以不能把“过牌多”直接叫成“有牌不打、比较保守”。
- 共同基线看当前局公开局面及当前局此前已经公开的对手行为。额外历史版本在
  相同基线上增加前三局记录。记录后再计数，预测输入不包含本次出牌结果。
- 当前局面分层包括出牌/跟牌、桌面牌型/张数/强度、持牌者关系、四席公开余牌数
  摘要、当前局进度、局号和公开等级、已打出的 joker/级牌数量；细层不足时按
  固定公式退回粗层。各层 64 个伪计数，历史似然固定除以 8，避免把同手牌内的
  多次行动当作独立证据。所有设置在汇总检验结果前写入 `protocol.json`。
- 参考组按已知冻结快照统计频率；检验时不提供快照身份，只根据公开行为给四个
  假设分配权重。身份标签仅用于参考分组和最终评分，不是检验特征。无梯度拟合、
  超参数搜索或神经网络更新；这是固定公式的频率表分析。
- 负对照：把前三局记录换成同一己方端点下其他 seed 的比赛记录，仍保持当前局
  输入不变。参考计数与随机打乱计划固定，不看检验得分挑选方案。

主评分为四分类 Brier score（概率预测的平方误差，越低越好）。先在每场比赛内
平均，再对比赛平均；报告“基线误差 − 带历史误差”，正值才是改善。对数误差为
次指标。按完整 seed cluster 配对，在四个对手层内做 10,000 次 bootstrap；
检验组共 128 个 seed cluster，每个含队伍互换和两种己方端点。

## 怎样排除当前牌和局面

**真实比赛分层只能控制记录下来的公开局面摘要，不能完全控制未观测的实际手牌。**
既不读私牌，就不能把这部分分析宣传为已经排除了所有手牌混杂。为此另做严格的
同牌题对照：

- 256 个预定开局种子，每个种子都给四个冻结对手完全相同的发牌和公开初始状态。
  只观察首个领牌者的公开动作，分为单张、炸弹类、其他三类。
- 每个对手每题 64 次独立采样，前 32 次只用于参考频率，后 32 次评分；同题不同
  对手使用相同抽样随机数，以降低比较噪声。共 65,536 个公开答案。
- 基线是同题的参考回答频率；历史版本仅额外使用检验比赛前三局推断出的风格
  权重。发牌种子不作为预测特征，不读取私牌或合法候选集来建预测表。真正的
  对手身份只用于选取检验标签，不能进入权重计算。
- 此处同一道题的实际手牌、桌面和轮到谁都相同，能排除当前发牌不同造成的差异。
  这是按题配对的实验控制，不是可直接上线的预测器：共同基线使用同题独立参考
  回答的频率。对历史 seed 和牌题同时重采样，报告交叉配对区间。
- **该对照只检验冻结对手可迁移的稳定打法**：牌题是新比赛的第一次领牌，模型的
  场内上下文为空。它不等于真实比赛第四局的反事实，也不能排除只在残局、跟牌
  或同场适应中才出现的历史信息。

## 公开信息边界与核验

[记录器](../../bench/public_history_probe.py)只导出公开事件白名单：环境/局索引、
公开步号、座位、出牌后公开余牌数、阶段、已公开的 action 编码，以及公开局末
等级结果。编码末尾八个私有进贡结构位必须全零，导出时再去掉。

正常对局玩家仍按规则看自己的牌来出牌；**分析器不读这些玩家的 observation、
候选集、critic 输入、隐藏手牌或 forced 标志**。collector 也去掉不必要的
`hidden_counts` 读取。前后等级只取上一局已经公开的结果；目标动作后的余牌数
不得反过来作为目标动作的预测特征。

六项定向测试：公开记录器拒读隐私属性、collector 不读 hidden counts、当前局面
特征在动作前构造且公开过牌正确闭合一墩、合成可区分打法能被公式识别、完全相同
打法不产生身份信息，以及追加残差公式的归一化/零残差不变性。与原比赛采样器的
四项检查合计 **10 passed**。合成表只是仪器测试，没有给真实比赛添加人工风格。

本轮仍是四个相隔仅六次 update 的快照；对手行为可能很接近。阴性结果不能推广
到所有对手或证明历史没信息；简单频率表识别不了复杂历史关系，也不能把阴性结果
单独归因为原 Transformer 不能学。

统计入口：[bench/public_history_analysis.py](../../bench/public_history_analysis.py)。
本地证据：`.work/public-history-probe-2026-10-16/`。该目录被忽略，非可移植依赖。
不修改主线训练实现，不创建/续跑训练作业，不据此自动加样本或改变对手池。

## 结果

### 完整性

17 个有界 worker 全部 exit code 0，补采样耗时 220.99 秒。1,024 场复跑的逐场
记录与原 FULL 比赛全部相同，覆盖 11,601 局、1,029,340 个公开事件。两个端点、
拥有模型/缓存实现及 native extension SHA 未改变。

独立检验组是 512 场 / 128 个 seed cluster，从第四局开始评分 **178,737 次对手
公开动作**，其中 28,649 次为领牌。另有 256 道同牌开局题、32,768 个参考回答和
32,768 个检验回答。重复抽样次数不被当成独立牌题或独立历史比赛。

### 预先固定的主诊断

真实比赛的平均 Brier 误差：只看当前局 **0.47293979**，增加前三局
**0.47294088**，几乎相同，带历史没有变准。下面正数表示历史更好：

| 检验 | Brier 改善 | 配对 95% CI |
|---|---:|---:|
| 真实比赛：当前局基线 − 带前三局 | −0.00000109 | [−0.00000395, +0.00000185] |
| 真实比赛：打乱历史 − 正确历史 | +0.00000354 | [−0.00000112, +0.00000852] |
| 同牌题：同题基线 − 带前三局 | −0.00000018 | [−0.00000290, +0.00000240] |
| 同牌题：打乱历史 − 正确历史 | +0.00000036 | [−0.00000248, +0.00000324] |

真实比赛的对数误差改善为 −0.00000406，95% CI [−0.00000967, +0.00000159]，
也没有改善证据。这些小区间是**这套固定频率表预测器的增益区间**，不是所有可能
历史预测器的能力上限，也不是“历史信息量为零”的证明。

描述性身份辨认检查：仅凭前三局判断四个近邻快照中的哪一个，正确率 **26.95%**，
按 seed cluster 的 95% CI **[23.24%, 30.86%]**，随机猜为 25%。后验最大概率
均值仅 25.73%，与均匀四选一很接近。因此不能把主诊断阴性说成“强预测器已证明
历史无信息”；它还受简单统计及四个已知快照组成的封闭候选集限制。

同题同随机数下，四个对手有至少一个回答属于不同动作大类的比例为 **6.40%**。
这说明在该开局题库中四者的粗粒度回答很接近；**不是**说其具体出牌完全相同，
也不涵盖跟牌、残局或同一快照内部的复杂历史适应。

### 探索性补查：直接延续行为偏差

在看到上述主诊断阴性后，增加[直接残差诊断](../../bench/public_history_residual.py)，
避免只靠辨认快照身份判断所有历史通道。对前三局每次公开动作，减去当前公开局面
基线的预期，分领牌/跟牌累计；从第四局开始用这些偏差直接调整基线概率。固定
32 个伪计数、不搜索参数、不增加比赛、参考/检验分组不变。**这是看到主结果后的
探索性补查，不是新的独立确认实验。**

| 检验 | Brier 改善 | 配对 95% CI |
|---|---:|---:|
| 真实比赛：基线 − 直接延续前三局偏差 | −0.001467 | [−0.001826, −0.001110] |
| 真实比赛：打乱历史 − 正确历史 | +0.000463 | [−0.000060, +0.000986] |
| 同牌题：基线 − 直接延续前三局偏差 | −0.003075 | [−0.003520, −0.002686] |
| 同牌题：打乱历史 − 正确历史 | +0.000015 | [−0.000540, +0.000578] |

直接照搬前三局的偏差会使该规则的预测更差，且正确历史没有可靠优于打乱历史。
这与把过去几局手牌、局面或抽样噪声误当稳定习惯相容，但本实验没有分别识别
这些原因，不能宣布“真实历史有害”或“所有记忆方法都会变差”。

### 用人话说与停止点

**目前没抓到稳定、可重复的“这个对手就是爱这么出”的公开线索。** 给这套统计
工具看前三局，没有更会猜后面的牌；让大家答完全相同的开局题也没有改善；简单
沿用过去的偏好还会误导预测。四个对手本来就是非常接近的快照，检验只覆盖过牌、
单张、炸弹等动作大类。现在不能把原因直接扣在 Transformer 不会用历史上，
也不能推广成“跨局历史本来没用”。

真实比赛仅控制公开局面摘要，同牌题只控制新开局的牌与局面；这两个范围不能合成
“所有真实后续决策的私牌影响都已完全排除”。本轮到此结束，不训练、不改生产
实现、不自动换对手或续采样。
