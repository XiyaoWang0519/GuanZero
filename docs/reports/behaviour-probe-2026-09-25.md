# 离线行为探针：管线检查与小规模诊断（2026-09-25）

状态：完成。本地 CPU，没有 GPU，没有 RL 更新，没有牌力主张。按
`docs/DESIGN.md` v0.6 和 `STAGE_C_TODO.md` 的边界，这是一个离线诊断工具，
不是新训练路线的入口，也不是任何门槛；它训出的权重不会进入任何策略。

## 做了什么

- 日志 schema 3（`train/logs.py`、`eval/collect_belief.py --candidates`）：
  每个决策记录 canonical 候选集合、每个候选的抽象编号（`Action.abstract_id`，
  393 个）和选中项；每个公开 token 记录抽象编号、强制过牌标记和阶段。
  旧格式和旧加载器不变；相关旧测试 77 个通过。
- `train/behaviour_probe.py`：公开事件流 Transformer 加私有 query（DESIGN 7.2
  形态），整场比赛一条序列，带局数嵌入；flat MLP 对照；三种策略头（候选打分、
  固定词表、结构化词表）；可开关的"预测本次决策会出什么"的公开信息辅助头
  （NTP）；`--window k` 对照让每个决策只看最近 k 个 token。所有指标按
  策略行 / 机器人行、领出 / 跟牌分格。15 个测试：因果掩码、私有信息不进公开流、
  窗口恰好只看 k 个 token、强制过牌标记不能影响模型、词表掩码、批量与单场一致。
- 本地数据：M1 自博弈 3,000 局；M1 对风格机器人（`--styled --style-region mixed`）
  3,000 局、590 场比赛，用于下表。

## 信息边界的一个发现

引擎的 `PublicActionEvent.forced` 只在该座位唯一合法动作是过牌时为真，也就是
"他压不了这手牌"。这是引擎私有的合法性信息，对手在真实对局里看不到。第一版
探针把它当 token 输入，已改掉：它只留在元数据里，模型输入不含它，有测试钉住。
T2 的事件存储必须遵守同一条。

## 结果（风格机器人数据，单 seed，宽 128、4 层，验证集早停）

指标在抽象动作层面计算，各头可比。"策略行"是 M1 的决策，"机器人行"是风格
机器人的决策。M1 是确定性的 argmax 策略，其选择由观测和候选完全决定，所以策略行
上 flat 就是天花板，历史不可能有增益；机器人行的风格向量不在观测里，是历史唯一
可能起作用的格子。

| 臂 | 策略行 CE / 准确率 | 机器人行 CE / 准确率 | 机器人领出 / 跟牌准确率 | NTP 准确率 策略 / 机器人 |
|---|---|---|---|---|
| flat + 候选打分 | 0.673 / 0.758 | 1.309 / 0.546 | 0.123 / 0.663 | 无 |
| flat + 固定词表 | 0.893 / 0.672 | 1.324 / 0.534 | 0.116 / 0.650 | 无 |
| flat + 结构化词表 | 0.913 / 0.670 | 1.320 / 0.536 | 0.110 / 0.654 | 无 |
| history + 候选打分 | 0.671 / 0.752 | 1.318 / 0.538 | 0.116 / 0.654 | 无 |
| history + 候选打分 + NTP | 0.822 / 0.763 | 1.436 / 0.532 | 0.121 / 0.646 | 0.312 / 0.332 |
| history（窗口 4）+ 候选打分 + NTP | 0.623 / 0.772 | 1.317 / 0.544 | 0.126 / 0.660 | 0.330 / 0.336 |
| history + 结构化词表 + NTP | 0.952 / 0.685 | 1.388 / 0.536 | 0.105 / 0.655 | 0.310 / 0.334 |

测试集 84 场、25,249 个决策（策略行 14,131，机器人行 11,118）。

## 读法

1. **管线通了。** 三种头、两种塔、窗口对照和 NTP 都能训、能评、损失有限；
   掩码和隐私由测试保证。这是本报告的主要交付。
2. **候选打分头明显好于两种词表头**（策略行 CE 0.67 对 0.89 以上）。结构化词表并
   没有救回来，所以差距不只是参数共享；更可能是候选的完整牌面（具体哪几张、
   打完剩什么）本身就携带词表没有的信息。这与 v0.6 "第一版用全部 canonical
   具体候选打分" 的决定一致。
3. **历史在这个规模上没有可测的增益。** 机器人行上 history 与 flat 相当
   （0.538 对 0.546）；只看最近 4 个 token 的窗口对照在 BC 和 NTP 上都不比整场
   历史差，甚至略好。这不是对历史价值的否定：3,000 局、单 seed、验证集在
   1,000 到 2,200 步就平台化，模型远未吃饱；而且行为克隆的目标本来就不是牌力。
   按 v0.6，历史是否有用由自博弈 RL 的牌力曲线决定，不由这个探针决定。
4. NTP 作为公开信息预测，能猜对约三分之一的下一手，领出局面几乎猜不中
   （对机器人领出 0.11 到 0.13）。这说明"从公开信息猜对手会出什么"在领出时
   本质上很难，任何辅助目标在那里的信号都弱。
