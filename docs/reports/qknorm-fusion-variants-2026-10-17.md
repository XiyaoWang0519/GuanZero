# 两端点不同融合方式的离线对照（2026-10-17）

状态：**全部完成。保持原宽度和冻结权重，可以把历史内容对出牌的影响放大；但这些方案尚未显示稳定的公开行为预测增益，不能宣称更会用历史或更能赢。** 未训练、未改主线、未采集新比赛。

## 范围与方案

承接[融合隔离](qknorm-fusion-isolation-2026-10-16.md)。仍为 control/qk-both
与 norm16 两端点。所有方案维度保持 128，不增加层、宽度或可训练参数；原
feed_forward、output_norm 和合法候选出牌头不变，只在第一处融合临时代换。

校准均值 q̄/r̄ 只由已有前 8 waves、每端点 256 个第 4 局 FULL 决策计算，不
使用核验样本或对手标签选择前向规则。这些均值只保存在离线证据目录，不接入
生产配置或 checkpoint。用真实 query 算出的 reader 始终保持原样；干预只发生
在融合阶段，不顺带改变上游 attention 如何读取历史。

令 q 为当前 query，r 为实际 reader，δ=r−r̄，σ 为 q+r̄ 的逐行标准差，γ 为
原 attention_norm 的 weight。第一处融合后的向量分别是：

| 条件 | 临时融合 |
|---|---|
| native | LN(q+r) |
| history2 | LN(q+r̄+2δ) |
| history4 | LN(q+r̄+4δ) |
| restore_mean | LN(q+r)+γ·mean(δ)/σ |
| postnorm1 | LN(q+r̄)+γ·δ/σ |
| postnorm4 | LN(q+r̄)+4γ·δ/σ |
| query_half | LN(q̄+0.5(q−q̄)+r) |

因此放大的是相对校准均值的内容变化，保留 reader 的共有背景项。restore_mean
只补历史相关均值；postnorm 在归一化之后补历史残差。所有条件都经过原有的
前馈残差、output_norm 和候选头，不为新条件重新训练下游权重。

完整事前方案在 `.work/qknorm-fusion-variants-2026-10-17/protocol.json`。

## 两类测量

1. **实际出牌影响**：重用 707 个同局面等长固定元数据替换样本，control
   357 个、norm16 350 个，各 64 个 seed 簇。自己的手牌、当前局公开记录、
   候选及顺序、真实 query、历史长度与位置不变，只换旧公开 token。记录
   每个方案 FULL 旧内容与替换旧内容之间的概率 TV/首选翻转，以及使用原
   历史时该方案相对 native 的漂移、熵与最大概率。不得删掉极端样本。
2. **是否保留有用线索**：重用已有 1,024 个第 4 局决策摘要，每端点 256
   校准、256 核验，128 个核验 seed 簇。对每种最终 state 用同一个固定闭式
   ridge（正则 N、缩放下限 .01）辨认已知四对手，再混合独立 256 道相同牌
   首出题的公开参考答案，评分使用独立公开答案。比较 FULL−ROUND，以及
   此差值相对 native 的变化。真实身份只用于校准标签和核验评分。

相同牌问题的 seed 簇×问题交叉 bootstrap 10,000 次，17102741/42；出牌影响
按 seed 簇 bootstrap 10,000 次，17102743。所有条件都报告，区间是探索性
描述，不作多重检验校正后的架构验收。已有样本此前已被分析，不是全新未触碰
的确认集；本轮没有模型训练、优化器、比赛强度测量或新增对局。

“策略漂移”是在**相同原历史**下，新融合相对 native 的平均 TV。

### norm16：350 个局面

| 方案 | 历史替换平均 TV | 历史首选改变 | 原策略平均漂移 | 原策略首选改变 |
|---|---:|---:|---:|---:|
| native | 0.446% | 2 | 0 | 0 |

| restore_mean | 0.477% | 2 | 0.061% | 0 |

history4 在第 2/4/8 局都增加内容敏感度：control 从 0.492/0.389/0.301%
到 1.924/1.546/1.174%；norm16 从 0.601/0.358/0.355% 到
2.451/1.444/1.406%。因此不是只在某一个局号出现放大。

history4 的整体原策略漂移平均不到 1%，不意味着所有单个局面或各局分组都
低于 1%。query_half 则大幅改变整个策略，不能把它较高的历史敏感度包装成
良好的融合修复；这也不等于已经测出棋力下降，本轮没有对局收益标签。

除 query_half 外，各方案平均动作熵保持接近 native：control 约 0.979–0.982，
norm16 约 1.155；没有出现无穷值或非法候选。query_half 的熵为 1.340/1.697。
完整 seed 均值、区间、最大值和逐行结果见 policy-summary.json/policy.json。

## 有用线索的核验结果

最终 state 对独立公开首出题的 FULL−ROUND Brier 改善：

| 方案 | control 改善 [95% CI] | norm16 改善 [95% CI] |
|---|---:|---:|
| native | −0.000116 [−0.000507, +0.000280] | −0.000131 [−0.000475, +0.000203] |
| history2 | −0.000262 [−0.000966, +0.000449] | −0.000509 [−0.001144, +0.000104] |
| history4 | −0.000493 [−0.001601, +0.000603] | −0.001154 [−0.002243, −0.000104] |
| restore_mean | +0.000032 [−0.000331, +0.000395] | −0.000110 [−0.000494, +0.000269] |
| postnorm1 | +0.000041 [−0.000323, +0.000406] | −0.000116 [−0.000507, +0.000268] |
| postnorm4 | +0.000048 [−0.000942, +0.001007] | −0.001156 [−0.002487, +0.000144] |
| query_half | −0.000220 [−0.001192, +0.000780] | −0.000606 [−0.001394, +0.000188] |

**没有任何方案在两端点上显示稳定的正向历史增益。** control 中 restore_mean /
postnorm1 相对 native 的变化有微小名义正值（约 +0.000148/+0.000157），
但它们自身的 FULL−ROUND 区间仍跨零，norm16 也没有复现，不能挑出来宣布
成功。norm16 部分放大条件的点估计反而更差；多条件探索性结果不等于确定
有害，更不是棋力结论。

postnorm4 的出牌内容敏感度与 history4 接近，未显示额外的有用线索优势。
因此这次较大的动作变化主要符合“增益放大了反应”，而不是已经验证了更好
的信息融合。除 query_half 外，各最终 state 的校准列标准差都高于读数缩放下限。
query_half 有 16/5 列低于 .01，其读数还受这个固定缩放影响，不能据此
宣称它删掉了历史信息；它约 50% 的实际策略漂移不依赖这个统计读数。

## 人话结论

**不加大模型，就能让历史更明显地影响出牌；但目前只是更敏感，还没证明
更有效。** 内容变化放大 4 倍后，历史替换导致的平均概率变化从约 0.4% 升到
1.6%–1.8%，首选改变从各 2 次变成 8/9 次，同时原策略整体漂移仍较小。

更温和的“保留均值”“归一化后补历史”只带来小幅变化，没形成可靠的预测
收益；直接压低手牌分支则会把原有策略大幅改动。当前没有可据此采纳的融合
修复，也没有证据证明必须增加模型容量。冻结权重没有适应新融合，只能用
这次结果筛查机制，不能替代公平训练对照或比赛胜率检验。
