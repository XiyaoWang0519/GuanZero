# 植入习惯诊断，第 0 阶段：校准（2026-09-30）

状态：已完成，只做测量。本地 CPU（Apple M4 Pro，10 个进程各 1 线程），没有训练，没有云实例，没有花费。计划见 [history-habit-diagnostic-plan-2026-09-29.md](history-habit-diagnostic-plan-2026-09-29.md)。本报告**不测试 Transformer 能否学会**，只回答：给对手植入一个固定的整场习惯后，之前各局是否提供额外的识别信息，以及对手是否因此变弱。

## 做法

- 四个座位都是 u2623（`.work/longrun-batched-eval-2026-09-29/ckpt/u2623.pt`，SHA256 `6fd3b94d…`），按自己的 softmax 采样出牌，进贡用引擎启发式（与训练相同）。源码为 `27d8dd8`。
- 每场比赛随机指定一队为"对手"，抽 z ∈ {−1, +1}，整场不变；对手每个出牌决策从 `pi_z(a) ∝ exp(l(a) + z·b·f(a))` 采样，所有合法候选仍然参与。另一队（观察方）看不到 z。
- 三个方向 f：**pass**（跟牌时选过牌，且存在可出的牌）；**bomb**（炸弹、同花顺、天王炸）；**lead_single**（领出时出单张）。"有机会"指这个决策里 f=1 与 f=0 的候选都有。
- 推理用训练时的公开 KV cache（`BatchedHistoryCache`）；每 5,000 步与整段重算对照，最大差 7.6e-6。
- 每个设置 10 个进程共 1,000 场完整比赛（约 11,000 局，约 85 万个出牌决策）。只保留运行结束前打完的比赛。
- 识别 z：在第 2 局起观察方的每个出牌决策处，只用它之前的对手决策：
  - **计数**（不用模型）：`k − n·p̄` 的符号，k 为选 f 的次数，n 为机会数，p̄ 为另一半比赛上的混合频率；
  - **理想观察者**：精确对数似然比 `Σ log pi_+(a)/pi_−(a)` 的符号。它用了对手私有手牌下 u2623 的概率，是任何学习者的**上限**，不是可达值。
  - 两者都分"只看本局"（A）与"看整场"（B）；增益 = B − A，区间按比赛 bootstrap（2,000 次）。"局初"指每局观察方的第一个决策。
- 强度：对手队每局净级数（赢则 +gain，输则 −gain），按比赛 bootstrap。
- 脚本：`.work/habit-phase0-2026-09-30/`（`collect.py`、`analyze.py`、`summarize_real.sh`），原始数据 `out/`，结果 `out/real_*.json`、`out/screen.json`。

另有一次离线初筛（`out/screen.json`，1,000 场无偏对局，在记录的局面上按 pi_z 重新抽对手的 f），趋势与下表一致；它假设局面不随偏好改变，只用于挑选设置。

**无偏基线不为 0 的原因。** 两队都是同一个 u2623、都不带偏好时，期望应为 0。按第 0 队视角算是 −0.004 [−0.058, +0.052]；"对手"标签每场随机指定，标签在第 0 队和第 1 队时分别为 −0.060 [−0.140, +0.017] 和 −0.051 [−0.128, +0.030]。最可能是约 2 个标准差的波动；因此下文比较强度时以基线为参照，并且不把小于约 0.08 的差别当作能分辨的差别。

## 结论

1. **之前各局提供了可观的额外识别信息，不用模型也拿得到。** 六个设置里，计数估计的跨局增益都在 +0.14 到 +0.22 之间，区间远离 0。局初只看本局近于瞎猜（0.50–0.62），看整场达到 0.72–0.93。计划要求的条件（a）成立。
2. **多数设置没有让对手明显变弱。** pass 两档、bomb b=1、lead_single b=1 与基线的差别都在 ±0.07 以内，分辨不出。bomb b=2 与 lead_single b=2 的 z=+1 一侧约 −0.19，比基线低约 0.13，已经明显变弱，排除。
3. **选定 lead_single b=1.0 作为第 1 阶段的主设置。** 理由：本局内最难认出（理想上限只看本局 0.666，是六个设置中最低的），跨局增益在理想上限下最大（+0.266 [0.254, 0.277]），计数下 +0.198，而且对手强度与基线分辨不出。备选 pass b=1.0：计数增益略大（+0.215），但理想观察者只看本局就有 0.824，存在计划里担心的"本局已经可见"问题。
4. 条件（b）"知道风格值多少"本阶段没有测，要由第 1 阶段 ORACLE 与 ROUND 的差来回答。lead_single 的机会只占出牌决策的约 17%，它的可利用价值可能偏小；如果 ORACLE ≈ ROUND，先换 pass b=1.0 再做判断。

## 局限

- "先打完的 100 场"会略偏向较短的比赛；各设置用同样的规则，比较是公平的，但绝对数值可能有轻微偏差。
- 理想观察者用了对手的私有手牌，只是上限；计数估计很粗，是一个容易达到的下限。学习者实际能达到的在两者之间，这里不做推断。
- 两个对手座位共用一个 z；计划里没有规定这一点，这里取最简单的做法。
- 强度只测了"带偏的 u2623 对无偏的 u2623"，没有测对其他对手的表现。
