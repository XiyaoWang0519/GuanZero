**协议与评分。** 使用冻结的五小时终点 `main-final.pt`，两臂仅改变是否开启现有搜索包装器。新 seed **2026092503**，50% 进贡设置；每副牌交换座位打两局，每个 arm 保存 5,000 条原始 leg，共 10,000 条。单副得分为 `(a.rewards[0] + b.rewards[1]) / 2`，只在两臂四条 leg 全部有效时计算搜索减原模型的差值。5,000 次整副牌 bootstrap 使用 seed+173；原评测器另用 2,000 次 bootstrap 得到 [0.00320, 0.01982]，差异来自重采样配置，结论一致。

排除的 deal IDs 是 **642、1868、2422**：前两副的 a leg、后一副的 b leg 在两臂均 `mirror_failed`。全部原始失败记录、有效 deal IDs 和逐副差值保留。固定 2,500 副样本与搜索参数在启动前确定，没有依据阶段性得分提前停止或调参。与昨晚 B11 的搜索收益是不同底座、不同牌集，不能相加。

搜索参数保持原样：未见牌数≤12 才触发，最多 4 个动作、4 个合法隐藏世界，至少完成 2 个世界，rollout 上限 120 步，每次搜索预算 500 ms，收益门槛 0.5、blueprint 人工先验 0.70。该采样没有使用真实对手暗牌，但仍是均匀合法重采样原型，尚不是学习到的信念分布。这次外部 harness 没有逐决策搜索延迟、触发或 fallback 记录，不能把昨晚内部测得的延迟当成此次延迟。
