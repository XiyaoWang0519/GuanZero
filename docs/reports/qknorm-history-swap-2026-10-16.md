# 两端点等长跨局公开历史替换（2026-10-16）

状态：**707 个同局面检查全部通过：两端点对旧历史内容有微弱反应，各只有 2 次首选改变；不能据此宣称学会对手适应或架构修复成功。** 用户授权冻结端点的同局面内容敏感度检查；
不训练、不更新权重、不改主线，不启动后续实验。

## 问题与范围

承接 [FULL/ROUND 比赛消融](qknorm-diverse-match-2026-10-16.md)。该消融会
同时改变旧历史内容、长度和当前事件的位置，整场路径不同不能单独证明对旧
历史内容有反应。本次直接固定决策输入，只改变之前各局的公开事件。

两个端点仍为隔离短 PPO 的 control（原始 qk-both）和 norm16；不是未经修改的
生产主线。端点 SHA 分别为：

- control：`a3d5e42ea6f6dc9a4b514f1bce948a061ee4be0b08c376dc8ce659ccf46948c7`
- norm16：`64d3fbd56bb7ea6968a4a54b3b7fd06f9d505c844920b2aa7c8636e4bcb22bdb`

## 固定方案

- 重放多样冻结对手研究的 wave 08–11，每个端点 128 场，64 个基础 seed、
  两队换座；不是新增独立胜率样本。对手是原定 u2623/u20264/u35588/u86800。
- 每场在第 2、4、8 局，取 learner 第一个至少两个合法动作的 PLAY 决策。
  提前结束的比赛本来不存在后面的局，不制造这些局；保留所有实际选中的局面。
- 供体使用独立 wave 00–07 和 12–15、同一端点的公开记录，合并之前近快照池
  和多样池，允许相同或不同对手；target wave 08–11 不进入供体池。
  learner 队伍不同的供体将公开座位统一旋转一位，保留相对队友/对手关系。
  每个供体比赛取 token 数最长的连续 k 个已完成局窗口（k=目标已完成局数），
  只按长度选窗口，不按模型反应或胜负选。再从足够长的窗口中固定 RNG 均匀
  选一个，取连续后缀，使替换事件数严格等于目标旧历史长度。
- 供体局序号平移到 0…k−1；当前局之前的 token、局序号和阶段整体替换。
  另做内容更严格的对照：替换同样的 token，但保留目标全部原始局序号和阶段。
- 每个局面独立计算四行：原历史、原历史复制、等长供体、等长供体但固定元数据。
  四行使用完全相同的当前观测、自己的手牌、seat、合法候选及顺序、当前局
  所有事件、总前缀长度、BOS 和当前事件绝对位置。
- 每个条件重新编码完整可见前缀，不复用修改前 KV。原样复制要求 logp
  最大误差 <1e−7，原历史复算与采样时真实缓存路径要求 <1e−4；失败直接停下。
- 供体只有公开行动、座位、剩余张数、局号和阶段；不读取 hidden_counts、
  forced、其他座位观测或合法候选。actor 正常使用自己的手牌，不向替换历史
  添加任何私牌、当前局未来事件或目标比赛的后续记录。
- TV 是整个合法动作概率分布的变化；改选率是最高概率动作是否改变，不是胜率。
  使用 64 个 seed 簇 bootstrap 10,000 次，保留同 seed 的两队座位和各局样本；
  同时报告逐行均值、各局覆盖、尾部和最大值，避免只看整场是否发生一次分歧。

### 长度规则修订记录

最初只准供体的最前 k 局。首轮四个 worker 因没有足够长的不同对手供体而
断言停止，未保存完整分析结果，没有删除目标样本。仅根据长度缺口，将供体
推广为任意连续 k 个已完成局窗口；第二轮仍有少数目标无法匹配。最终扩大到
已有近快照池/多样池的全部独立 seed 供体，并允许同一对手在另一场的公开历史，
队伍不同时只旋转公开 seat 编码。没有按反应大小或胜负选择供体或删除目标样本。
两次失败的样本与日志保留在 `attempt-1-first-k-too-short/` 和
`attempt-2-different-opponent-too-short/`。正式结果只使用完整通过的重跑。

## 结果

正式四个 worker 全部 exit 0，耗时 **63.53 秒**，CPU 推理，无训练。
256 场重放记录全部与上次 FULL 结果一致，全部实际存在的目标局都取到指定
可选决策。control 覆盖第 2/4/8 局 128/128/101 行，共 **357**；norm16 为
128/128/94 行，共 **350**。第 8 局缺少的行均因比赛此前已经结束，无长度
不匹配或数值失败导致的丢样本。

### 内容与元数据一起替换

| 端点 | 首选改变 | 平均 TV（逐行） | 平均 TV（先按 seed 均值，95% 簇区间） | TV 中位数 / p95 / 最大 |
|---|---:|---:|---:|---:|
| control | 2/357，0.560% | 0.3216% | 0.3190% [0.2747%, 0.3653%] | 0.1688% / 1.1639% / 3.3968% |
| norm16 | 2/350，0.571% | 0.3967% | 0.3958% [0.3436%, 0.4517%] | 0.2336% / 1.3236% / 4.7412% |

TV×100 表示重新分配了多少百分比的概率质量，不是准确率或胜率百分点。
有 TV>1% 的行分别 28/357、33/350，没有 TV>10% 的行。
bootstrap 区间描述抽样波动，不把非负 TV 的区间当成有效对手适应的显著性检验。

### 进一步固定旧历史局号和阶段，仅替换公开 token

| 端点 | 首选改变 | 平均 TV（逐行） | 平均 TV（先按 seed 均值，95% 簇区间） |
|---|---:|---:|---:|
| control | 2/357，0.560% | 0.4011% | 0.3971% [0.3420%, 0.4559%] |
| norm16 | 2/350，0.571% | 0.4461% | 0.4420% [0.3837%, 0.5030%] |

这组连过去每个 token 的 round/phase 标签也不改变，仍能产生小幅响应，说明
观察到的反应不完全来自历史长度、当前绝对位置或旧局号/阶段变化。

四次首选翻转在两种替换下完全相同，全部发生在第 2 局。本来的前两名概率差
为 control 2.24/2.98 个百分点，norm16 0.70/0.96 个百分点，是原本较接近的
候选，不是大幅改写非常确定的决定。各指定局的首个决策只代表本次抽样位置，
第 4/8 局没有翻转不代表这些局的所有决策都不受内容影响。

### 数值、身份与覆盖校验

- 707 行原样复制的 logp 差全部 **0**；所有候选概率有限。
- 原历史新编码与真实 KV 推理最大 logp 差：control **3.0518e−5**，
  norm16 **3.8147e−5**，均通过 1e−4 门槛；内容扰动的典型概率变化明显更大。
- 端点、四个冻结对手、模型源码和 native 扩展 SHA 在执行前后全部一致。
- 替换旧事件长度 control 59–740，norm16 62–750；全部当前局后缀、自己的
  观测与候选顺序不变，总 prefix 分别 63–742、66–755。
- control 供体近池/多样池为 174/183 行，norm16 为 153/197 行；多样池中
  同一对手另一场供体分别 49/51 行，其余供体为不同模型。公开 seat 旋转
  对齐 learner 队伍分别 178/181 行。
- 四个新替换边界测试及既有公开采集/消融/多样选择测试共 **14 passed**。

## 人话结论

**旧历史里具体出了什么牌，确实会让模型略微调整出牌概率；但影响很弱。**
把长度、位置、当前牌局，甚至旧局号和阶段都固定，两端点仍有响应；不过
各自约 99.4% 的所测局面首选没有改变，平均只重新分配约 0.4% 的出牌概率。
因此不能再说“完全不看内容”，也不能把上次整场路径全分叉理解成强烈依赖
历史。范数 16 没有表现出明显更多的首选改变，两端点抽样局面与 donor 不完全
相同，本实验不做修复优劣的因果比较，更没有验证历史带来胜率收益。


## 解释边界

这是对输入内容的离线敏感度实验，不测胜率，也不证明反应正确、学会识别对手
或修复了架构。供体窗口裁切可能从一局中间开始；拼接的过去可能与当前级数、
上局名次和当前观测不一致。固定元数据对照还可能让 donor token 与原 phase
标签不一致。这些都是分布外干预，阳性只能说明响应内容变化，阴性也不能
证明所有真实历史信息均无用。局面只取每个指定局的首个可选决策，不能代表
所有局中阶段。两个端点、四个对手和同一训练 seed 限制推广范围。
