# u195450 下一步出牌预测：读取结构 × 容量 — 2026-11-14

状态：用户授权的前两步已完成。固定 u195450 与同一份 filtered 对手池，在独立副本比较原 attention 读取结构、改进读取结构的小版/大版，并检查正确历史能否改善下一次对手公开出牌预测。没有改主线、训练 PPO、接回出牌策略或测棋力。

**本轮没有建立正确历史的额外预测收益，也没有得到扩大读取器能解决问题的证据。** 原结构小/大版与改进小版都被验证集选回零历史分支；改进大版只有一个优化种子保留训练后的分支，在新测试集上没有改善。真实身份参照同样没有可靠增益，因此结果不能证明历史无用、整个模型容量足够，或已经找出 RL 不学历史的唯一原因。

## 2. 预测任务与可见信息

标签为：**我方已观测的实际动作之后，同一局下一次对手公开 Play 的 11 种 action type**。包含 pass、单张、对子、三张、三带二、顺子、三连对、钢板、普通炸弹、同花顺、四王。训练/验证/测试中四王目标均为 0，本轮不评价它的单类能力。

所有版本接收同样的 545 维当前上下文：我方原生 private query、只编码本局的冻结 state、我方已选动作、我方座位、当前前缀长度/局号/采样阈值、本局公开行为统计。预测目标是条件于我方实际动作的下一次对手出牌，不是对所有我方候选动作同时估值。

历史分支只接收前三个已完成局的公共流及其冻结 encoder 表示。旧局与本局分别编码，旧局分支不含本局未来事件。对手手牌、合法集、forced 标志和类型编号不进入四个被测读取器；真实身份只进入单独的特权诊断组。

所有旧 token 自动按**相对座位 × 距今局数**整理为 12 组，加一个 BOS 组。所有公开阶段和席位保留，没有只截上一局某位对手的“答案范围”。两种结构都获得相同的公开组编号、组内 token 数；分组不查看牌型或预测标签。

## 3. 四组结构和容量如何匹配

“原结构”保留线性 Q/K/V 的 attention 读取形式。本轮四组从相同规则重新初始化**离线预测读取模块**，不是把已有小 reader 的权重与随机大 reader 混着比较。u195450 的 encoder/private 网络冻结；原生预训练 reader 另有冻结参照组。

| 组 | 读取方式 | 可训练 reader 参数，不含共同预测头 |
|---|---|---:|
| original_small | 全部旧 token 的线性 attention，内部 128 维、8 heads | 67,840 |
| original_large | 同结构，内部 256 维、8 heads | 133,760 |
| improved_small | 逐 token MLP，按公开组 mean+max，合并后 attention 读取各组 | 67,872 |
| improved_large | 同结构，扩大 token MLP 与组间 attention | 133,760 |

改进组的 token MLP 分别为 `128→64→128` / `128→128→128`，LeakyReLU；每组 mean 与 max 拼接后 `256→128` 合并，组间 attention 内部维度分别为 32 / 128。所有组输出 128 维，使用相同下游预测头。小版跨结构只差 32 个参数，大版参数量完全相同。分配给 token 特征处理与 attention 的参数比例不同，这是比较的结构选择；计算量并不相同。

四组共同使用训练集统计标准化、per-head Q/K LayerNorm 和稳定的 LeakyReLU 头。这样避免已知 Q/K 饱和与诊断头失活掩盖容量比较。此结果描述经过共同数值处理的结构学习能力，不等于原主线 reader 已经接受这些修正。

### 当前基线与历史增量

先按每个优化种子训练 `当前上下文→128 LeakyReLU→11` 的当前局面基线，再冻结它。历史组预测为：

`冻结当前基线 logits + 残差头(当前上下文表示, 历史读出)`。

共同残差头为 `256→64 LeakyReLU→11`，最后一层零初始化，使第 0 步精确等于当前基线。历史读出使用训练 batch 的 BatchNorm，并在每次候选 checkpoint 用全部训练样本重新校准；验证/测试不参与统计。所有组都允许验证集选第 0 步。

额外参照：相同残差头但历史恒为零的 `current_extra`；真实类型 embedding；原始公开历史统计；冻结 u195450 原生 attention 对旧局的读出。后者仍用原始尺度，是不同于重新初始化四组的参考。

## 4. 新测试结果

主指标是 **11 类 Brier 概率预测误差，越低越好**。每场先平均其捕获点，再平均同牌的两种方位，最后按池权重汇总；三个优化种子先平均，不能当成三倍样本。这里普通动作准确率与前一轮的历史事实平衡准确率不是同一个指标。

| 组 | 正确历史 Brier | 打乱旧历史 Brier | 普通动作准确率 |
|---|---:|---:|---:|
| 只用训练类别频率 | 0.698573 | — | 47.04% |
| 只看当前局面的基线 | **0.479400** | — | **66.96%** |
| 原结构小版 | 0.479400 | 0.479400 | 66.96% |
| 原结构大版 | 0.479400 | 0.479400 | 66.96% |
| 改进小版 | 0.479400 | 0.479400 | 66.96% |
| 改进大版 | **0.480992** | **0.480818** | 66.37% |
| 告知真实对手身份 | 0.478537 | 不适用 | 67.24% |

`current_extra`、原始历史统计、冻结原生读出也均选择零残差，测试预测与当前基线逐项相同。

改进大版相对当前基线的 Brier 改善（基线误差减该组误差）为 **−0.001592，配对 95% CI [−0.005966, +0.002984]**；十二项预定比较的调整区间为 [−0.008031, +0.004968]。没有确认改善，也没有确认它一定更差。

改进大版正确历史相对打乱历史的改善为 **−0.000174，95% CI [−0.000726, +0.000419]**；调整区间 [−0.000958, +0.000667]。正确匹配的历史没有显示可靠预测收益。

真实身份参照相对当前基线为 **+0.000863，95% CI [−0.001431, +0.003306]**，同样未建立稳定增益。这是受限预测头的身份参照，不是理论最优 oracle。

### 为什么三组数字完全相同

这不是舍入，也不是未执行训练。原结构小/大版、改进小版的三个种子都在验证集选择**第 0 步零残差**，所以其测试函数确实等于当前基线。改进大版仅 seed 72 选择了 lr=0.001、第 200 步；另外两个种子仍是第 0 步。

因此三组正确/打乱差为零，区间也为 [0,0]，只是**所选模型完全没有启用历史分支**。这不构成历史信息量的零区间估计，不能据此声称三种架构潜力相等或历史无用。

### 同一对手、另一场历史

在首次新测试评分前，额外封存一个仅推理的对照：取同类型、同我方座位、不同牌种子的历史，优先保持采样阈值。它保留对手类型，破坏本场历史细节。

改进大版此时 Brier 为 0.480756；正确历史相对它的改善为 −0.000235，95% CI [−0.000865, +0.000386]。仍未检测到差别。由于主要历史收益本来就没有建立，这个结果不足以进一步分解风格信息与本场信息的贡献。

## 5. 优化没有停住，主要观察是过拟合

四个主配置各有 6 次运行，共 24 次，全部实际完成 2,000 步。每组排除第 0 步后记录 168 个预定采样点，**历史特征梯度和 Q 投影梯度均为 168/168 非零**。第 0 步因残差输出刻意为零而暂时不向 reader 传梯度，是初始化设计，不是 ReLU 失活。

| 组 | 末步训练 Brier 范围 | 末步验证 Brier 范围 |
|---|---:|---:|
| 原结构小版 | 0.003–0.013 | 0.617–0.678 |
| 原结构大版 | 0.001–0.009 | 0.636–0.706 |
| 改进小版 | 0.004–0.051 | 0.610–0.642 |
| 改进大版 | 0.001–0.011 | 0.602–0.697 |

对应三个基线的验证 Brier 是 0.4964 / 0.5021 / 0.4803。读取器能拟合训练轨迹，增加容量也能降低部分训练误差，但没有转化成可靠的新对局预测收益。不能把这个观察写成“模型根本没有优化”或“更多参数一定有用”。

## 6. 对此前结论的补充

[历史事实实验](history-reader-mechanism-2026-11-14.md)的 94.74% 证明特定事实可从冻结 encoder 中学会解码；本轮没有推翻它。本轮换成未知手牌下的未来动作预测，并且自动汇总全部旧局，已经是更难、不同的任务。

本轮仍没有通过“历史事实→可泛化的对手行为预测”这一关。它不支持现在因容量假说而改主线，也不支持把新的 mean/max 读取器接入主线后直接预期棋力改善。

仍未分开的原因包括：三局历史是否足够识别这些相邻 filtered snapshots；自然局面中当前上下文已经解释了多少行为；单次随机轨迹标签和隐藏手牌噪声；800 场独立训练比赛是否足够；残差学习、正则化、checkpoint 间隔及本轮结构是否合适。冻结 encoder 的容量限制也没有通过“只扩大 reader”被排除。

[先前相同手牌的重复抽样任务](filtered-history-diagnosis-2026-11-13.md)曾测到真实身份的行为预测收益；本轮自然轨迹任务没有稳定复现身份增益。两者的条件、目标与估计方法不同，不能互相替代。若继续，优先应在可辨识的重复局面预测任务中校准身份正参照与公开历史识别，再决定扩大数据、容量或做策略训练。本轮没有启动这些后续工作。

## 7. 统计、预算与验证

- 6 次当前基线运行 + 48 次历史/参照分支运行，共 **54 次运行、108,000 次离线诊断更新**。三个种子 71/72/73，两种学习率 0.0003/0.001，每次 2,000 步、batch 32，AdamW weight decay=0.001、clip norm 1；训练目标为池/比赛加权 CE，没有按类别重平衡。
- 每 200 步按验证 Brier 选 checkpoint，再选学习率；包含第 0 步。所有选择在测试评分前封存。没有用新测试结果追加学习率或更换配置。
- 本地 CPU，最多 4 个 worker、每 worker 一个 torch thread；全部运行时长合计约 1,112 秒（并发任务时长之和）。无远端训练操作或新算力租用。
- 5,000 次按固定对手类型分层的配对牌种子组 bootstrap，保留两种方位和所有捕获点。十二个预定主要对比另报 alpha=0.05/12 的区间；其它参照是描述性 95% 区间。区间条件于已选模型，不覆盖完整优化随机性与未来新对手分布。
- 主打乱对照在同 split、同我方座位、同阈值、不同牌种子之间置换旧历史；保留 receiver 的当前输入。没有跨座位旋转重编码问题，但长度与旧局具体状态可以变化。测试置换用于检查依赖，不等于重新训练一个打乱历史模型。
- 独立扫描原始 `public.npz` 复核全部 **3,837 个未来动作标签**；检查 **1,017,611 个公共 token 的分组**、前缀边界、私有标志、donor 约束和新测试种子不重用。
- **35 个相关测试通过**，覆盖目标的局/座位/阶段边界，公开分组不读答案，padding/空组，参数预算匹配，零残差基线一致性，训练统计隔离，以及缺少捕获点时仍按比赛/种子组正确加权。
- actor、population、owning training source 的 SHA 未变，原 actor 对象每次分支训练后逐参数验证未改；`train/`、`cpp/` 没有本轮改动。协议封存时实现尚在完成，实际训练源码 hash 另在所有运行记录中一致保存。
