# GuanZero 跨局历史利用调查：QK-norm、融合机制与训练经历完整报告

日期：2026-10-17。覆盖本次对话中 2026-10-16 至 17 日的实验与取证，以及为解释结果而复查的历史记录。

用途：供 GPT 6 Astra Pro 或其他研究审阅者理解问题、复核证据、判断后续实验。本文自包含主要配置、结果与限制；原始分项报告、脚本和本地产物见文末。它是综合报告，不是新的实验结果或训练授权。

## 1. 目前能得出的结论

**公开跨局历史有小幅可预测信息；现有两个模型端点的编码器和历史读取向量中也能读出这种信息，但历史内容对最终出牌的影响很弱，尚未可靠证明能提高完整比赛胜率。**

这组结果支持以下分层判断：

1. **不是“历史完全没进训练”。** owning source、11 个 checkpoint 配置和真实 PPO batch 都支持整场公开历史进入学习路径。
2. **不是“出牌收益完全传不到历史”。** backward-only 检查得到旧局 token 的非零 PPO 梯度，未来 token 梯度为零。
3. **不是“历史编码器完全没记住有用信息”。** 冻结编码和实际 reader 都可以帮助预测独立的同牌公开出牌题。
4. **更值得怀疑的是后段融合与使用。** 加入当前 query、再经归一化及后续层后，固定线性读数对这些线索的利用明显变弱。这里的 query 含当前自己的手牌和局面信息，并非单纯的“手牌张量”。
5. **不能认定是 LayerNorm 实现错误或模型容量不足。** 固定 query 变化后，保留原 LayerNorm 仍可读出线索；大多数历史扰动的几何能量也没有被抹除。现有离线对照不足以区分权重不适应、表示/优化偏置、训练机会不足和容量上限。
6. **故障期确实发生了额外退化，但弱历史使用早于故障。** 不能用“以前架构坏了，现在修好了”概括整个过程。
7. **norm16 是通过短程数值稳定性检查的候选，不是已验证有效的修复。** 它增加了 Q/K 方向更新幅度，却没有自动改善历史敏感度或跨局收益。

全文必须区分四件事：**历史有信息、表示保留信息、策略会对内容变化作出反应、这种反应能够多赢。** 本次对前两项有较明确的局部证据，对第三项发现弱反应，第四项仍不确定。

## 2. 研究起点、模型与授权范围

### 2.1 为什么从 QK-norm 查到历史使用

此前主线出现 masked efficient-SDPA backward 异常；相同输入下 CUDA 路径可以出现极大的 V 梯度，math SDPA 路径正常。既有故障调查还发现，旧模型 private attention 的 score 极大、注意力近 one-hot、query 方向高度一致，部分 Q/K 数学梯度为零。

这涉及两个相关但不能混为一谈的问题：

- **算子正确性：** backward 是否算错。math fallback 是此前已验证的工程处置。
- **表示与学习：** 即使 backward 正确，极端饱和和方向共线是否使历史读取难以学习、有内容却不会用。

原清单提出了产物核验、机制探针、完整比赛消融、外部评测、对手辨认与 CUDA 内核机制等任务。本次按用户逐步授权，先做已有产物和离线诊断，中间单独批准过一次有限的完整 PPO A/B，随后回到冻结评测和离线取证。**不能将整个对话写成“从未训练”；也不能将早期短程训练授权延伸成后续长训授权。**

CUDA 内部概率/LSE 重建的具体错误机制仍未由本轮内核级证据证明。CPU/FP64 attention 重算可以揭示饱和，但不等于历史 CUDA kernel 的逐位重放。

### 2.2 三臂 500M 与后续两端点是两组不同命名

“500M”指从共同 u86800 起点新增约 5 亿个训练 decisions，**不是模型有 5 亿参数**。三臂匹配保存点均为 u94488，新增实际计数 503,840,768 decisions，总计 6,192,365,568。

| 阶段 | 条件 | 含义 |
|---|---|---|
| 已有三臂 500M | control | query_norm=false，qk_norm=false |
| 已有三臂 500M | query | query_norm=true，qk_norm=false |
| 已有三臂 500M | both / qk-both | query_norm=true，qk_norm=true |
| 后续短 PPO 与全部历史诊断 | control | **原始 qk-both** 继续 120 updates 的端点 |
| 后续短 PPO 与全部历史诊断 | norm16 | 同一 qk-both parent，Q/K 范数和 Adam 矩迁移后继续 120 updates 的端点 |

因此后文两端点的 control **不代表无归一化三臂 control，也不代表未经分支变更的主线模型**。两端点均为宽度 128、4 层、8 heads 的 Transformer，来自随机初始化自博弈谱系。

### 2.3 本次实际边界

- 没有采用候选改变主线模型、生产训练配置或主线 checkpoint。
- 唯一新增的策略训练是用户明确批准的隔离短 PPO：每臂 120 updates；不是新的 500M 长训。
- 其后均为冻结模型评测、一次性前向干预、闭式统计校准或不执行 optimizer step 的梯度检查。
- 用户另行批准后，已从 velocity 只读下载三份已有故障期 checkpoint，并核验 SHA；没有为此启动训练或修改远端作业。
- 本报告撰写没有新增比赛、模型训练、参数更新或后继实验。本文不声称其他无关作业当前处于任何状态。

## 4. QK-norm 机制、范数缩放与短程 PPO

### 4.1 三臂 500M 核验

核对服务器原文件、评估副本、本地副本、checkpoint 内 source identity 及实际模型文件，三臂 u94488 身份一致。机制探针用原真实 fixture 的 328 行，加三组 fresh 数据各 192 行，共 904 个决策行；CPU FP32 math SDPA，实际 Q/K 的 attention 分布另以 FP64 重建。

qk-both 解除了原有的极端 one-hot 与 fixture 上的零 Q/K 梯度，但 query 仍高度共线。用独立校准的平均 reader 替换实际 reader，策略 TV 平均约 1%；清零 reader 的影响约 20% 或更多。更合理的解释是 reader 的共有背景部分对策略很重要，但随历史内容变化的部分作用较小。清零强影响不等于模型强烈利用了具体对手历史。

已有单局内部强度结果：both−control 约 +0.006，95% CI [−0.0458,+0.0580]；query−control 约 −0.0265，[−0.0770,+0.0255]。它们不是本次新增比赛，区间跨零，也不能证明等效。单局重置历史的评估本身不回答跨局适应问题。

三臂人口池也进行了对应归一化迁移，所以其结果属于完整配方，不能只归因于 learner 的单一开关。[R1]

### 4.2 逐 head 范数调整的定义

每个 head 将相应 weight 行和 bias 联合展平：

`θ_h = vec(W_h, b_h)`

`a_h = min(1, target / ||θ_h||₂)`，`θ'_h = a_h θ_h`。

Q 与 K 分别逐 head 缩放；K 只处理联合 kv_proj 的前半块，V 后半块保持不变。Q/K 的 weight 和 bias 使用一致系数，query_norm、温度、其他权重不变。原 Q 联合范数约 22.71–113.72，K 约 19.98–101.16。

归一化使正尺度变化后的前向近似相同，RMSNorm 的 eps 和浮点误差使它不是严格函数恒等。测试 target=16、8、4、2.309401，四数据集、三调用路径共 48 组比较；路径复用 904 行，不能当成更多独立数据。所有比较通过：最大 log-prob 差约 4.01e−5，最大 TV 约 4.05e−6，argmax 翻转为 0。[R2]

切向梯度定义为：

`g_tan = g − θ ⟨θ,g⟩ / ||θ||²`。

尺度不变近似下，`g'≈g/a`，内在方向梯度 `||θ||·||g_tan||` 保持，同学习率 SGD 的相对方向步幅约放大 `1/a²`。实测梯度坐标关系最大相对误差约 1.91e−4。**缩放改变步幅，不创造有用信号或自动增加 query 多样性。**

### 4.3 为什么采用 m/a、v/a²，而非重置联合 K/V 状态

原 Adam：lr=3e−4，betas=(0.9,0.999)，eps=1e−8，weight_decay=0。保存的投影状态 step=2,787,152，计数的是 minibatch optimizer steps，不是 PPO update。

梯度变为 g/a 后，采用：

`m' = m/a`，`v' = v/a²`。

只迁移 Q/K 切片，保留共享 step、lr、eps、V 和其他参数状态。这是保留梯度历史的坐标处理，**不保持原 Adam 函数轨迹**。若要求纯坐标变换、保持原轨迹，还需逐 head `lr'=a·lr`、`eps'=eps/a`；这里固定 lr/eps，目的正是改变后续动力学。eps 主导元素比例也发生变化，所以实际步幅倍数不必等于简单的尺度公式。

一次性 outcome-loss Adam 反事实中，target16 + 矩迁移的 Q/K 转角倍数中位数为 9.42×/5.68×，一步后相对原 native 步最大策略 TV 3.44e−5；V 更新逐位相同。只清矩保留成熟时钟，并不等于 fresh Adam；清整块 K/V 矩与 step 的反例则改变 V 更新。不能为了重置 K 顺手重置共享 V 时钟。

target16 是保守工程候选，不是经训练搜索确定的最优范数；一次性反事实也不代表完整 PPO 轨迹。[R2]

## 5. 历史有没有潜在价值：公开行为预测

### 5.1 为什么先查“历史是否值得学”

FULL/ROUND 没测出胜率差，至少有两种解释：当前模型不会用，或者测试对手的历史本身难以提供额外信息。为分开二者，固定 actor 权重，用前三局公开行为去预测第四局及以后对手的 pass/single/bomb/other。

预测器使用固定统计计数表，不训练神经网络。控制当前公开局面和当前局行为；真实对局中仍不能完全观测对手私牌，因此另设**同一副牌、相同公开起点的首出题**，用相同实际牌控制手牌差异。预测器只接收公开参考行为，不读取对手 hidden_counts、forced 标记或私有观测。

Brier 定义为类别概率的平方误差和；以下 gain 为 `Brier_without_history − Brier_with_history`，正值更好。相对误差下降不等于胜率或准确率提升。

### 5.2 近邻对手池

1,024 场既有 FULL 比赛精确重放，11,601 局、1,029,340 个公开事件。512 场校准，512 场核验，128 个核验 seed 簇，178,737 个第四局起对手动作。

- 历史 Brier gain：−1.09e−6，95% CI [−3.95e−6,+1.85e−6]。
- 256 道同牌首出题 gain：−1.79e−7，[−2.90e−6,+2.40e−6]。
- 由历史辨认四个对手：26.95%，CI [23.24%,30.86%]，机会值 25%。
- 对手同牌公开动作类别分歧率仅 6.40%。

这只能说明此固定预测器在近邻池没检出可靠增益，不能证明历史普遍无信息。[R6]

### 5.3 更大差异的冻结旧 Transformer 池

从八个已有原生 Transformer u675/u2623/u9989/u20264/u35588/u58528/u73780/u86800 中，用独立 64 道开局题的类别 TV 做 maximin 选择，选出 **u2623、u20264、u35588、u86800**。筛选没有使用后续核验收益或比赛胜负。它们只是评估对手，未加入训练。

正式独立题的类别分歧率为 **54.82%**，明显高于近邻池。1,024 场完整比赛、10,351 局、944,584 个公开事件；核验共 166,660 个对手动作。

| 指标 | 近邻池 | 多样旧对手池 |
|---|---:|---:|
| 真实后续行为 Brier gain | −0.00000109 | **+0.00010981** |
| 多样池该 gain 的 95% CI | — | [+0.00008467,+0.00013534] |
| 真实后续行为相对误差下降 | 未确立 | **0.024%** |
| 同牌首出题 Brier gain | −0.000000179 | **+0.00212414** |
| 多样池同牌 gain 的 95% CI | — | [+0.00157719,+0.00272376] |
| 同牌相对误差下降 | 未确立 | **0.706%** |
| 四对手身份识别率 | 26.95% | **41.02%**，CI [36.91%,45.12%] |

正确历史优于打乱历史。直接沿用前几局行为偏差的简单 residual 规则仍然更差，说明“有可预测信息”不等于“任意历史启发式都有用”。

结论范围是：**在这四个已知冻结对手中，前三局公开行为对后续粗类别出牌提供小幅额外预测信息；同牌开局对照支持这种差异不只是手牌不同。** 它不证明陌生对手泛化、最优反制动作或比赛收益。新数据内部 alias 47241–47244 指所选四旧模型，不能与旧近邻池模型身份混淆。[R7]

## 6. 完整比赛 FULL/ROUND：是否真的多赢

FULL 保留整场公开历史；ROUND 每局重建 BOS/当前局位置与本局历史视图。learner 两个队友使用所选视图，对手始终 FULL。因此干预同时改变历史内容、长度、位置和缓存视图，不能仅凭此隔离“历史语义”。

每个对手池均为 2 端点×2 视图×512 场=2,048 场；256 个配对 seed 簇，保留两队换座。置信区间以 seed 簇而非每个动作独立 bootstrap。多样池使用按对手分层的配对 seed bootstrap。

| 近邻 / control | 150，29.30% | 133，25.98% | +3.32 | [−1.56,+8.01] | [−2.15,+8.59] |

| 多样 / norm16 | 366，71.48% | 372，72.66% | −1.17 | [−5.27,+2.93] | [−5.86,+3.52] |

近邻池 23,196 局，多样池 20,593 局。近邻池为共同 parent 附近的 u94482/94484/94486/94488；多样池为上一节四个旧模型。两个池的绝对胜率不可直接比较为模型进步。

多样池 control 有 20 场净胜的弱正向迹象，不能说“完全没有收益信号”；但单项 95% 正区间没有通过预定双比较门槛，不能宣布已经确立收益。norm16 的负点估计也不足以证明损害。两端点历史收益之差约 −5.08 pp，95% CI [−10.16,0]，97.5% CI [−10.94,+0.78]，未确立 norm16 改善。[R5,R8]

多样池两端点各 512/512 配对整场公共路径都分叉，所有首局配对 hash 一致。一次小动作差异就能使后面整场轨迹分叉，**100% 路径分叉不是 100% 决策依赖历史，也不是已经学会辨认对手**。

公开预测分析中的全部 1,024 场 FULL 正是这些对应 FULL 比赛的精确重放，不是额外独立样本。上述两池 FULL/ROUND 合计 4,096 个条件比赛，不能再把预测采集、层间分析和重放次数累计成独立强度样本。

## 7. 同局面等长替换：模型到底响应历史内容吗

为排除 FULL/ROUND 的长度等因素，固定自己的 obs/手牌、座位、合法候选及顺序、当前局 token、前缀长度与位置，只换之前各局的公开 token。

重放 256 场既有 FULL 比赛，每端点 128 场、64 seed 簇，在第 2/4/8 局各取第一个非平凡 learner 决策。早结束比赛不伪造后续局，共 control 357 行、norm16 350 行。供体来自不重叠 seed 的已存公开记录；按可供长度选择完整旧局窗口并截取等长后缀。前两次供体长度限制失败记录保留，扩大供体范围后完成，没有删除目标行。

有两种交换：自然交换并重映射供体 round/phase；更严格的交换保留目标全部 round/phase 元数据，仅替换旧公开 token 内容。核心结论取后者：

| 端点 | 等长内容替换平均 TV | argmax 翻转 |
|---|---:|---:|
| control | **0.4011%** | **2/357，0.560%** |
| norm16 | **0.4461%** | **2/350，0.571%** |

`TV(p,q)=0.5·Σ_a |p_a−q_a|`；表中为 TV×100，不能当成胜率下降。原历史重复前向完全相同，fresh encode 与实际 cache 的最大 logp 差 <3.82e−5；全部翻转在第 2 局、原先概率差较小的决策中。

所以答案是：**历史具体内容确实会影响模型出牌概率，但平均影响很弱，首选动作很少变化。** 拼接的旧历史可能与当前级数等不完全相容，存在分布外问题；它没有证明模型识别了正确风格、选择了更好的反制或多赢。[R9]

### 对“以前历史不影响出牌、现在架构修好了”的纠正

复查 2026-09-29 u2623 对单一 B11 的旧报告，原始表格本来就有 FULL/ROUND 约 0.82% 的 argmax 变化，SWAP 约 0.08%，NONE 约 1.1–1.5%。原文“没有可测量的依赖”若理解为严格零反应，措辞过强；更准确是没有确立强度收益，内容依赖很弱。

旧实验对手、checkpoint、取样位置和指标都不同，不能直接把旧 0.08% 与新约 0.56% 的差解释为架构修复效果。历史算子修复和 qknorm 的确有数值证据，但**没有建立“过去历史完全断路，现在已修好并有效利用”的因果链**。[R14]

## 8. 编码器没记住，还是后面没用上

### 8.1 冻结分层读数

精确重放多样池全部 1,024 场 FULL，各取第 4 局 learner 第一个至少两个合法动作的决策。每端点 512 行，256 校准、256 核验；核验 128 seed 簇。对以下激活使用同一固定闭式 ridge：

- 旧 token / 旧对手 token 的 encoder memory 均值。
- 实际 attention 后经 out_proj 的 reader。
- 最终送入候选动作头的 decision state。

固定标准化下限 .01、ridge 正则 N×1、先验截距、概率下限 1e−4；不搜索超参，不更新 actor。校准用四对手标签，核验身份仅用于评分。另设含当前 query、ROUND reader、历史长度的条件基线，以及同 seed 分组的打乱对照。

“有用”采用独立 256 道同牌首出题：从激活推断对手概率，再混合四对手公开参考行为分布，对独立公开答案计算 Brier。这不是在线给 actor 输入真实身份或私牌，也不是动作最优性评估。

| 读数 | control | norm16 |
|---|---:|---:|
| 旧对手 memory 独立身份识别率 | 48.83% | 45.70% |
| reader 独立身份识别率 | 42.19% | 39.84% |
| 最终 state 独立身份识别率 | 28.91% | 26.56% |
| memory 同牌题 gain，相对均匀先验 | +0.018035 | +0.015811 |
| reader 同牌题 FULL−ROUND gain | **+0.009649** | **+0.008167** |
| reader gain 的 95% CI | [+0.005379,+0.014153] | [+0.003687,+0.012969] |
| 最终 state 同牌题 FULL−ROUND gain | −0.000116 | −0.000131 |
| state gain 的 95% CI | [−0.000510,+0.000282] | [−0.000470,+0.000208] |

这些结果反对“编码器完全没有保留风格信息”。memory 和真实 reader 中的线索可预测公开行为；最终 state 的固定读数未检出稳定额外收益。后者不等于信息论上已无信息，非线性表示、噪声和有限样本都可能影响线性读数。[R10]

### 8.2 query、中心化、缩放的分离

实际融合路径概括为：

`x=q+r → attention_norm(x) → feed_forward 残差 → output_norm → decision state → action head`。

后验逐层拆解发现同牌 gain 从 reader 的约 .00965/.00817 降到 q+r 的 .00358/.00355，再到中心化/归一化后接近零或负。query 跨局面变化 RMS 约 31，而 reader 约 .38/.46；量纲和尺度差只能提示混合问题，不能单独证明因果。

随后用事先固定的因子对照，将融合处 query 换成校准集均值，**上游 reader 仍由真实 query 算出**，并分别测试不归一化、仅减均值、减均值并缩放、加 learned affine：

- 真实 query 下，仅减均值已令剩余线性 gain 变弱，额外缩放/affine 没有显示主要独立效应。
- 固定 query 波动、保留原生 LayerNorm，仍有正预测增益：标准化 floor=.01 时约 .00620/.00518；预定 floor=1e−6 敏感性检查约 .00920/.00798。
- 因此“只要存在 LayerNorm，历史线索就必然被消灭”不成立。

对 707 个等长内容替换计算 reader delta 的几何分解：均值方向占平方能量 7.32%/7.96%，径向 .58%/.64%，切向 92.10%/91.39%；实际有限变化扣除整体单位缩放后仍保留约 92.03%/91.33% 的扰动能量。**这不是保留了 92% 有用信息。** 少量方向可能承载可读线索，多数能量也可能无用；但不支持 LN 几何上擦掉了绝大多数内容扰动。[R11]

较稳妥的机制表述是：**当前 query 的变化与融合/中心化共同使历史线索难以被现有后段使用**；尚无证据确认 LN bug、信息彻底丢失，或删掉归一化即可提高胜率。

## 9. 不加大模型，换融合能否改善

冻结所有权重，保持 128 维，不加层、不加可训练参数。令校准均值为 q̄、r̄，δ=r−r̄，σ 为 q+r̄ 的逐行标准差，γ 为原 LN weight。比较：

| 方案 | 融合输出 |
|---|---|
| native | LN(q+r) |
| history2 / history4 | LN(q+r̄+gδ)，g=2/4 |
| restore_mean | LN(q+r)+γ·mean(δ)/σ |
| postnorm1 / postnorm4 | LN(q+r̄)+gγ·δ/σ，g=1/4 |
| query_half | LN(q̄+0.5(q−q̄)+r) |

全部继续经过原 FF/output_norm/action head；均值仅由原校准集计算，不用核验标签选择规则。

| 方案 | 历史替换 TV，control / norm16 | 历史翻转次数，control / norm16 | 原历史下相对 native 的策略 TV |
|---|---|---|---|
| native | 0.401% / 0.446% | 2 / 2 | 0 / 0 |
| history2 | 0.797% / 0.897% | 4 / 4 | 0.221% / 0.275% |
| history4 | **1.576% / 1.802%** | **8 / 9** | **0.662% / 0.828%** |
| restore_mean | 0.412% / 0.477% | 3 / 2 | 0.043% / 0.061% |
| postnorm1 | 0.418% / 0.484% | 3 / 2 | 0.045% / 0.064% |
| postnorm4 | 1.649% / 1.924% | 7 / 8 | 0.669% / 0.859% |
| query_half | 0.495% / 0.547% | 2 / 5 | **52.312% / 49.918%** |

结论：同样大小的网络，改变融合就能放大历史内容影响，**所以不能把弱敏感度直接当成必须加大模型的证据**。但没有方案在两个端点最终 state 中都产生稳定正向 FULL−ROUND 同牌题 gain。query_half 则严重改变整体策略，不是低扰动候选。

未适应新融合的旧权重可能限制测试，放大无关变化也可能增加 TV。以上均未测比赛强度；不能宣称融合修复有效或同宽模型容量足够。已有核验样本被反复分析，结果属于探索性诊断，不是全新确认集。[R12]

## 10. 训练经历和收益信号是否完整

### 10.1 整场历史进入 learner 的证据

核对主线与匹配 qknorm 分支 owning source：

- MatchEventStore 按比赛保留 raw public tokens，换局不清空整场历史。
- 采集行保存各自 prefix；training_batch 裁掉最大已引用 prefix 后的未来后缀，不裁旧局。
- minibatch_loss 重新编码 raw stream，未拿 rollout 的 detached KV 作为不可训练的 learner 表示。
- 11 个 checkpoint 都是 window=0、habit_view=full。max_rounds=16 是局号 embedding 上限，不是只存 16 局；本次固定第 4 局对照不检验更晚局号别名。

真实隔离完整 PPO fixture：328 行、8 条 stream，prefix 0–852；**296/328 行可确认有旧局 token**，最多 781 个，确定旧 token 占每行可见前缀的比例均值 80.64%。fixture 不存逐行当前 round，使用最后已见事件的 round 作保守下界，不读取未来推断标签。

短 PPO 日志学习 mean prefix 平均 524.40/542.34，最高 learn_max_prefix 2,049/1,973。日志长度本身不证明内容正确，但结合 raw fixture 和代码，不支持“系统性只把本局送入训练”。这不是所有数十亿 decisions 的完整录像。[R13]

### 10.2 练习对手与奖励边界

被查配置：snapshot cadence=2，recent=4，snapshot probability=.5，archive_every=0。新比赛从最近四快照抽样；旧模型因比赛未结束而 resident/pinned，不等于仍可分给新比赛。

实际短 PPO assignment：control 1,334 场分配、norm16 1,262；四席均为当前 learner 的比例约 11.02%/11.09%。冻结快照在分配时仅落后 0–7 updates，均值 3.49/3.50。每场身份固定、冻结快照 pinned；身份 0 的当前 learner 仍随训练更新，不能称所有对手整场都冻结。

这支持“不同且持久对手的练习条件有限”的解释，但 update 距离不是行为差异的替代量，也不是整段历史训练的逐场人口统计。

奖励为每局 seat_return，GAE 在局末 terminal：

- 后几局的当下 PPO loss **可以**通过历史读取教旧 token 表示。
- 前几局为后几局试探对手的行动，**没有后几局奖励直接跨局回传的信用**。

因此不能把每局 GAE 截断解释成“历史学不到任何东西”；它主要限制主动跨局试探的直接学习目标。[R13]

### 10.3 只求梯度，不更新参数

使用 torch.autograd.grad，未创建 optimizer、未 step，参数值逐位不变、`.grad` 未累积。原 fixture 保留原 stored action/logp/behaviour_logp/advantage 与 advantage moments，使用 owning PPO 公式，clip fraction 4.88%。输入仅 actor 自己 obs、公开流及已有训练标签；不调用 critic，不读 belief hidden 标签。本段不是完整 actor loss 的所有分项审计。

| 目标 | encoder 参数梯度范数 |
|---|---:|
| 纯 PPO 出牌收益 | **0.004615** |
| next ×0.1 | **0.246111** |
| outcome ×0.1 | 0.007266 |
| response ×0.1 | 0.000191 |

同 encoder 参数组中 next 加权范数约为 PPO 的 53.3×，是一个 batch 的量级观察，**不是全程辅助目标主导的证明，也不能忽略梯度夹角**。

7 条确认有旧局的晚期行：旧局 encoded 梯度范数 0.02151，public projection 梯度约 0.000366，占可见 token 平方梯度分别约 76.98%/83.90%；未来后缀梯度 0。原 fixture Q/K weight 梯度约 4.14e−9/2.16e−8，V 约 .0275；尺度坐标不同，不能仅凭小 Q/K 原始范数断言学习能力。

当前端点也有 encoder、Q/K 和旧 token 的非零 PPO 梯度，但它们使用当前 policy 重锚 logp/behaviour，只保留旧 advantages，因此是**连通性检查，不是真实 on-policy 更新或收益方向验证**。不能把 .02031/.03318 的当前 encoder 梯度与原 fixture 直接比较为学习改善。[R13]

## 12. 哪些解释被削弱，哪些仍待区分

| 解释 | 当前证据判断 | 还缺什么 |
|---|---|---|
| 跨局公开历史完全没有价值 | 在已测多样四对手池中不成立；价值小且限于粗行为预测 | 陌生/混合对手、复杂决策和反制收益 |
| 历史没有送进 learner | 代码、配置、真实 batch 不支持系统性缺失 | 更长跨度抽样，不是当前优先主因 |
| PPO 完全教不到历史 | 局部 backward-only 已反驳 | 不能据此保证梯度足够大、方向正确或优化成功 |
| encoder 完全没记住 | memory 与 reader 的独立公开题增益反对该解释 | 更丰富任务、非线性和决策相关性 |
| LN 把所有历史抹掉 | query 因子与几何对照反对 | 学习后的因果收益，而非只看表示尺度 |
| 当前融合/后段使用不充分 | 多项探索性证据支持，优先调查 | 权重适应与架构改变的受控比较 |
| 模型容量太小 | 未证明；同宽已能编码信息和放大敏感度 | 相同训练条件/预算的容量对照 |
| 训练没有充分练到跨局利用 | 对手近邻、round-terminal GAE、单 batch 信号比支持其合理性 | 直接操控训练经历和收益目标的因果对照 |
| 故障是唯一原因 | 故障前弱使用和非单调结果反对 | 不能从时间线还原未发生的无故障训练 |
| norm16 已修好历史利用 | 数值和短程稳定通过，历史/强度收益未通过 | 独立、多 seed 的收益验证；当前未授权 |

## 13. 原清单完成情况与后续问题

### 已完成的范围

三臂匹配 500M 产物核验；机制和范数可塑性；Adam 切片迁移；健康 CUDA/完整 actor loss；有限完整 PPO A/B；两池 FULL/ROUND 完整比赛；公开预测、同牌控制和多样对手筛选；等长内容替换；分层与融合离线对照；训练经历、无 step 梯度及故障期时间线。

### 没有在本次完成的范围

原清单的 100M/250M/500M 全机制时间曲线、当前两端点新的 DanLM 外部强度评测、CUDA 内核 LSE/概率重建的内部定位、新的 planted-habit ORACLE 训练、从头训练的 reduced-history 对照、多训练 seed、较大模型容量对照和任何长训，均不能写成已完成。旧项目的相关实验不等于这次针对当前端点完成了它们。

### 建议交给审阅者判断的问题（仅提案）

1. **先定义决策上值得利用的历史任务。** 目前同牌粗类别预测说明有风格信息，但幅度小；怎样用严格公开输入构造稳定且有反制收益的任务，避免把“辨认四个模型”当成策略能力？
2. **怎样区分权重适应与融合结构？** 冻结权重的放大对照已到解释边界。若未来批准有限训练，应同时保留同宽原融合继续训练、同宽候选融合适应组，保持数据/目标/预算与评估规则可比。
3. **怎样区分练习不足与容量不足？** 需要把训练对手差异、目标信用边界和模型容量分开操控，至少不能同时换大模型、换人口池和换奖励后宣称容量是根因。可先分阶段设计，避免一次因子过多而样本不足。
4. **是否值得改跨局信用？** 被动利用历史与主动试探是不同任务。round-terminal GAE 不阻断前者，但后者若要成立，需先定义训练边界、收益评价与计算预算。
5. **如何避免重复使用核验集？** 现有数据已支持机制探索；任何修复验收都应有新 seed/新对手与事先固定的主要指标，按训练 seed 和 match seed 的正确层级处理不确定性。

以上不授权执行训练、增加算力、改变主线或自动续跑。当前可以继续的报告审阅和实验设计，不等于这些训练实验已获批准。

### 14.3 审阅时应保留的限制

- 两端点来自单训练谱系和单 continuation seed，不支持多 seed 因果推断。
- 多样池是同谱系的四个已知模型；已知身份预测不能代替未知真实对手适应。
- same-card 题只控制首出起点的实际牌，不等于全程任意局面都已排除所有潜在混杂。
- 公开预测只看四种粗类别；信息量、预测误差、最优行动和比赛收益是不同指标。
- 内容替换、固定 query 和新融合可能分布外；强激活或高 TV 不能自动当成有益反应。
- 线性读数没有增益不能证明信息消失；有增益也不能证明原 actor 的动作头会利用它。
- 故障时间线包含持续训练与人口变化；不能完全分离修复、学习和样本分布效应。
- 后期融合分析多次复用样本，区间主要用于探索性描述；强度实验采用其原先预定门槛。
- 私牌边界需按实验区分：公开历史预测、层间及最新训练审计不读取对手私牌；早期完整 actor-loss gate 包含既有 belief 辅助损失的训练标签，但标签未作为 actor 观测/缓存输入。不能将“actor 没偷看”误写成所有辅助 loss 都完全没有私有监督标签。
