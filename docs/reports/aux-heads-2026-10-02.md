# Auxiliary heads on the history encoder (October 2, 2026)

Status: implemented, gated on a 5090 and run as a three-arm night (Oct 2/3); results below.

## Why

u9989 (654.6M decisions) is +0.67 levels/round against B11 and -1.73 against
DanLM. Its decisions show no measurable dependence on earlier-round history,
and the T7 response head (one 23-class label per own decision, coefficient 0.1)
is saturated at 0.76 accuracy. DanLM trains a comparable encoder with a
next-token loss at every stream position plus a dense value signal. The agreed
experiment adds that supervision, and two targets DanLM does not have, to the
shared encoder of a trained lineage, then measures the policy against DanLM.

## What

`train/history_aux.py`, `HistoryPolicyConfig.aux_heads`, `HistoryPPOConfig`
`aux_heads` / `aux_coef` / `aux_warmup_updates`, and `extend_actor`.

| head | input | target | loss |
|---|---|---|---|
| `next` | every encoded stream position (position s has seen s tokens) | public token s: seat, type, key, wild count and cards-left as one-hot fields; the two card planes as multi-hot; bomb size with a "not a bomb" class | mean over the eight fields of the field cross-entropies and mean binary cross-entropies, over valid positions (positions below each match's longest cited prefix) |
| `belief` | decision state | stored hidden counts [3, 54] (relative seats +1, +2, +3) | per unseen copy, negative log-probability of the seat that holds it; baseline = hand-size proportional guess |
| `outcome` | decision state | the acting team's round return | squared error; baseline = target variance |

Each head is a width-wide hidden layer plus a linear map (12 tensors, 93,654
parameters at width 128). Heads are created from a forked RNG stream so the
base actor and the critic are initialised exactly as without heads. They are
registered last, so a checkpoint without heads extends by `strict=False`
loading with the missing keys verified to be exactly the head keys, and the
saved Adam state maps onto the first parameters (the habit-init precedent).

Labels: `next` labels are the uploaded streams shifted by one position, with
no extra host work; `belief` labels are the `hidden` field the critic already
receives; `outcome` labels are each row's trajectory reward
(`round_outcomes`). No label reaches the actor's inputs.

## Checks run (Mac, CPU)

* `tests/test_history_aux.py` (8 tests): canonical config and record, base and
  critic initialisation unchanged, policy bitwise unchanged with heads on and
  after `extend_actor`, next-token alignment and padding, belief loss values,
  outcome labels, length-group and full-stream losses agree, warm-up ramp,
  resume-with-heads end to end (lineage, optimizer moments, population
  snapshots, checkpoint round trip, head removal refused).
* Existing suites touching the trainer, model, population, habit, eval and DDP:
  211 passed, 22 skipped.
* Heads off: three single-threaded updates in the production configuration
  (auxiliary response mode, length groups 2, batched learner attention, KV
  cache, snapshots) are bitwise identical to commit `fabcb71` for the actor and
  critic weights. Multi-threaded CPU runs are not reproducible run to run even
  on the old code, so that comparison needs `torch_threads=1`.
* u9989 weights: `extend_actor` leaves candidate log-probabilities bitwise
  unchanged on 541 collected decisions; its 13 population snapshots load; its
  Adam state (step 284,834) maps onto the 91 base tensors.
* CPU cost at width 128, 4 layers, 32 envs: learn 0.379 s (none), 0.393 s
  (`next`), 0.403 s (all three) per update; collect unchanged.

## Gate (Oct 3, 00:10-00:40 EDT, two RTX 5090 on host 406325, $0.80)

Two 0.6 h runs from u9989 with all three heads: coefficient 0.1 without
warm-up, and 0.03 with a 100-update warm-up (kits `.work/aux-heads-2026-10-02/
kits/gate-{a,b}`). Every CUDA gate passed, including a new `auxheads` gate
(`tests/test_history_aux.py` on the pod). approx_kl, clip_fraction and entropy
stayed inside u9989's last-200-update band throughout (kl 0.005-0.007, clip
0.046-0.056, entropy 0.44-0.48); learn +6.5%, collect unchanged. B11 curves of
the nine checkpoints per arm (256 deals, paired against u9989's +0.668) sat at
+0.41..+0.71 (means +0.52 and +0.59). Head-free main-lineage neighbours on the
same deals (u8928 +0.47, u9672 +0.51, u8060 +0.43) sit in the same band, so
u9989's +0.668 is a high draw and there is no evidence of an insertion shock;
the two coefficients cannot be distinguished. The night used 0.1 without warm-up.

## Three-arm night (Oct 3, 00:52-09:05 EDT, three RTX 5090, $11.9, 0 restarts)

All from u9989, fast-lg2 + MPS, 8 h, checkpoints every 124 updates
(`kits/{control,next,full}`). DanLM: 4,000 deals, seed 20260929, ±0.035.

| arm | heads | endpoint | decisions | vs DanLM (levels/round) | round win | vs B11, mean of 2nd-half checkpoints |
|---|---|---|---|---|---|---|
| u9989 (start) | | | 654.6M | -1.729 [-1.765, -1.694] | 17.2% | |
| control | none | u15168 | 994.1M | -1.635 [-1.671, -1.598] | 18.7% | +0.720 |
| next (A) | next token | u15062 | 987.1M | -1.649 [-1.685, -1.614] | 18.2% | +0.718 |
| full (B) | next + belief + outcome | u15094 | 989.2M | **-1.558 [-1.594, -1.521]** | **20.1%** | +0.742 |

* full - control against DanLM: +0.077, intervals barely disjoint (unpaired,
  about three standard errors); next - control: -0.014, indistinguishable. The
  training run-to-run noise (~0.04, one seed per arm) is not in these intervals.
* B11 (same 256 deals, paired over the 20 second-half checkpoints): full -
  control +0.025 [-0.022, +0.072], last ten checkpoints +0.040 [-0.024, +0.110];
  next - control +0.008 [-0.039, +0.054]. B11 cannot distinguish the arms.
* By tribute type (DanLM): full gains on every type; anti-tribute deals -1.46 vs
  control -1.78 (229 deals, noisy).
* The control's night gain (+0.094) is below the previous night's (+0.23 from
  u4902 to u9989): the curve against DanLM is flattening.
* Heads at the end (last 200 updates): next-token loss 0.38, type accuracy
  0.745, seat accuracy 0.997, all 108 card bits right 53%; belief 0.924 vs the
  hand-size baseline 1.039 (0.115 nats per unseen copy); outcome MSE 3.75 vs
  variance 5.33. Policy entropy 0.42-0.43 in all arms; response accuracy 0.76.
* Cost: learn 1.92-1.93 s vs 1.84 s (control), collect unchanged; per night
  about 3% fewer updates (5,105 and 5,073 vs 5,179).

Reading: the next-token head alone did nothing measurable; the belief and
outcome heads added together are the best single-night result so far
(-1.558, the strongest model against DanLM). One seed; a replication or a
longer run decides whether to keep the heads in the lineage.
