# Auxiliary heads on the history encoder (October 2, 2026)

Status: implemented and CPU-tested; no GPU gate and no training result yet.

## Why

u9989 (654.6M decisions) is +0.67 levels/round against B11 and -1.73 against
DanLM. Its decisions show no measurable dependence on earlier-round history,
and the T7 response head (one 23-class label per own decision, coefficient 0.1)
is saturated at 0.76 accuracy. DanLM trains a comparable encoder with a
next-token loss at every stream position plus a dense value signal. The agreed
experiment adds that supervision, and two targets DanLM does not have, to the
shared encoder of a trained lineage, then measures the policy against DanLM.

## What

`train/history_aux.py`, `HistoryPolicyConfig.aux_heads`, `HistoryPPOConfig`
`aux_heads` / `aux_coef` / `aux_warmup_updates`, and `extend_actor`.

| head | input | target | loss |
|---|---|---|---|
| `next` | every encoded stream position (position s has seen s tokens) | public token s: seat, type, key, wild count and cards-left as one-hot fields; the two card planes as multi-hot; bomb size with a "not a bomb" class | sum of field cross-entropies and mean binary cross-entropies over valid positions (positions below each match's longest cited prefix) |
| `belief` | decision state | stored hidden counts [3, 54] (relative seats +1, +2, +3) | per unseen copy, negative log-probability of the seat that holds it; baseline = hand-size proportional guess |
| `outcome` | decision state | the acting team's round return | squared error; baseline = target variance |

Each head is a width-wide hidden layer plus a linear map (12 tensors, 93,654
parameters at width 128). Heads are created from a forked RNG stream so the
base actor and the critic are initialised exactly as without heads. They are
registered last, so a checkpoint without heads extends by `strict=False`
loading with the missing keys verified to be exactly the head keys, and the
saved Adam state maps onto the first parameters (the habit-init precedent).

Labels: `next` labels are the uploaded streams shifted by one position, with
no extra host work; `belief` labels are the `hidden` field the critic already
receives; `outcome` labels are each row's trajectory reward
(`round_outcomes`). No label reaches the actor's inputs.

## Checks run (Mac, CPU)

* `tests/test_history_aux.py` (8 tests): canonical config and record, base and
  critic initialisation unchanged, policy bitwise unchanged with heads on and
  after `extend_actor`, next-token alignment and padding, belief loss values,
  outcome labels, length-group and full-stream losses agree, warm-up ramp,
  resume-with-heads end to end (lineage, optimizer moments, population
  snapshots, checkpoint round trip, head removal refused).
* Existing suites touching the trainer, model, population, habit, eval and DDP:
  211 passed, 22 skipped.
* Heads off: three single-threaded updates in the production configuration
  (auxiliary response mode, length groups 2, batched learner attention, KV
  cache, snapshots) are bitwise identical to commit `fabcb71` for the actor and
  critic weights. Multi-threaded CPU runs are not reproducible run to run even
  on the old code, so that comparison needs `torch_threads=1`.
* u9989 weights: `extend_actor` leaves candidate log-probabilities bitwise
  unchanged on 541 collected decisions; its 13 population snapshots load; its
  Adam state (step 284,834) maps onto the 91 base tensors.
* CPU cost at width 128, 4 layers, 32 envs: learn 0.379 s (none), 0.393 s
  (`next`), 0.403 s (all three) per update; collect unchanged.
