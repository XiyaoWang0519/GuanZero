# u195450 / 当前 filtered 池：历史信息与分层利用诊断 — 2026-11-13

状态：两步冻结诊断已完成；结论有明确的统计和任务范围限制。用户授权用 u195450 和当前 filtered 池检查历史额外价值、定位利用环节，并要求不动主线训练。全部模拟、探针拟合和 activation 干预在本地 CPU 完成；未运行 PPO、optimizer step、GPU 作业或主线配置修改。

**本轮没有建立“正确历史能增加回报”的证据。对手之间确实存在可预测的行为差别，但本轮公开历史探针没有恢复出有用的身份后验。私有 attention 读出近似常量、对最终动作影响很小的现象，在当前 filtered 池上再次复现。** 不能据此断言历史本身无用，也不能把整个问题唯一归因于稀疏奖励、filtered 或某一层丢失了所有信息。

## 1. 冻结身份和实验边界

- Actor：u195450，SHA-256 `e4a3c989e01ca3f83665bca83c82897dc045e52bb20c5143a86fe27b1a9fd3c2`。
- 对手池：只读取得主线 **u196664** 保存点的 filtered population，SHA-256 `a5f4673410c291ecd00b5adaee2869f967ca72412935179ec585876783135fbb`。这是采集时封存的池；主线继续推进，不把它称为持续实时的“最新”。
- 使用全部 20 个 eligible native snapshots：16 个 archive、4 个 recent，覆盖 u196000–u196664。按条件于 snapshot 分支的真实采样权重汇总：archive 每个 0.03125，recent 每个 0.125；完整 native identity、acting hash 在机器可读记录中。
- 每场两名对手共用同一个冻结快照，我方两席均用 u195450。这是便于识别风格的受控分布，**不是**主线混合席位、含 current learner 的完整训练分布。
- 只读使用 checkpoint；公共探针不接收对手手牌、合法动作集、forced 标记或真实身份。真实身份只作为监督标签或明确标记的特权 oracle。模拟器为对手执行策略时当然需要其自己的手牌，但这些数据没有交给公共观察者。

## 2. 数据与评价方法

### 公开历史和分层探针

20 种对手 × 32 个独立牌种子 × 两个队伍方位，共 **1,280 场四轮对局**。同一种子在两种方位下配对；不同类型和 replicate 的种子独立。训练/验证/测试按整组种子划分为 20/4/8 个 replicate，测试有 160 个独立牌种子组、320 场对局，避免把同场多个决策当独立样本。

每场在第 2 轮开头，以及第 4 轮当前公开 Play 事件数达到 0/20/50 后的首个非强制我方决策采样。共 5,120 个 activation 样本；其中 1 个之后本轮没有对手动作，不能构造预测标签，保留原输入但不计入预测评分。主要探针使用第 4 轮：3,839 行，测试 959 行。activation 干预仍使用全部 960 个第 4 轮测试决策。

预测标签是我方实际出牌之后，本轮下一次对手公开出牌的类别：pass、single、bomb、other。所有探针共享 545 维当前上下文：我方 query、本轮单独编码的 state、我方已选动作、方位/阶段和当前公开行为摘要。分别增加 128 维：

1. 前三轮公开动作统计；
2. 前三轮对手公开 token 的 encoder 平均表示；
3. 实际 cross-attention 读出；
4. 实际最终 decision state。

模型参数冻结；只拟合 ridge 统计探针。标准化只用训练集，正则强度只按验证集 Brier 选取，测试标签不参与选型。Brier 越低越好。四项主要比较采用 **98.75% 种子组 bootstrap 区间**；其它诊断为描述性 95% 区间。Brier 水平按池权重汇总行，增益先在种子组内平均；缺失一行使两者的差有微小区别。

### 独立相同手牌问题

128 副全新的相同开局手牌，每种对手 64 次策略抽样；前 32 次校准公开行为分布，后 32 次评分。同一题内对手的手牌与随机数配对，校准和评分抽样独立。观察者只能看到最终公开出牌类别，不读取概率 logits、私牌或合法集。

前三轮历史的公共身份探针只使用历史统计或历史 encoder 表示，不使用当前私有 query。其测试后验用于回答这批独立问题，检验历史是否能恢复可预测差别。

### 独立决策价值

从中性的 u195450 对局中按公开牌数/我方手牌条件，顺序取 **12 个独立来源的中后盘信息集**，不按回报或对手差异筛选。每处保留 3–4 个合法候选，包含原策略首选；对手类型在评分节点才赋值。隐藏手牌只按当前信息集均匀重采样，不将实际隐藏真值交给选招者。

每类型/候选使用 **32 个选招世界**估值，先平均隐藏世界再取 argmax。封存不知道身份、知道真实身份、仅有公开历史后验三种方案的动作之后，再用 **64 个独立评价世界**配对评分，共 **82,560 个完整回合分支**。只改变当前一步，后续仍由冻结策略执行。主要指标为 PPO team round return，附带本轮胜率。

这是有限候选、固定后续策略、均匀隐藏配牌下的局部诊断，不是自然完整比赛的历史价值上界。历史后验来自同类型的独立参考比赛，不是这个中性评分局面的真实先前对局。

## 3. 第一步：可预测差别存在，历史带来的回报未建立

### 知道身份能预测一些不同打法

在独立相同手牌问题上：

| 信息 | 测试 Brier | 相对不知道身份的改善；95% 区间 |
|---|---:|---:|
| 池先验，不知道身份 | 0.162406 | — |
| 告知真实身份 | 0.150210 | +0.012195 [0.007426, 0.017800] |
| 从前三轮公开统计推断身份 | 0.162406 | +0.000000174 [−0.000000938, 0.000001252] |
| 从前三轮 encoder 表示推断身份 | 0.162399 | +0.000006292 [−0.000073055, 0.000081559] |

因此不能说“filtered 对手全一样”。但 **oracle 的行为预测优势不等于公开历史可识别，也不等于存在可赚的级差**。前三轮公开统计后验与池先验的平均 TV 只有 0.000869；其身份 Brier 0.921903，也没有胜过先验的 0.921875。encoder 后验也没有改善身份 Brier。

### 独立隐藏配牌没有确认收益

| 方案相对不知道身份 | 本轮胜率增量；95% 区间 | PPO 回合回报增量；95% 区间 |
|---|---:|---:|
| 真实身份选招 | −0.297 pp [−1.473, +0.684] | +0.001994 [−0.047040, +0.059083] |
| 公开历史后验选招 | 0：所有动作相同 | 0：所有动作相同 |

真实身份在 27.08% 的加权条件下改变首选；公开历史后验在全部 12 × 320 个条件下没有改变先验动作。后者的零差值是**这两套已选策略完全相同**，不是对历史最优价值的零区间估计。

估值精度明显不足：把 32 个选招世界分成两半，身份首选一致率只有 **44.01%**，先验首选一致率 41.67%。选招样本内身份方案看似多 +0.02588 回报，独立评分只剩 +0.00199。不能把这个结果解释成“身份没价值”或“奖励再怎么改也学不到”；本轮保留为有独立评价的有限精度诊断，不把分支数当成 82,560 个独立局面。

## 4. 第二步：目前不能画出风格信息在哪层消失；读出弱利用可以复现

在同一批第 4 轮测试决策上：

| 增加的历史特征 | 测试 Brier | 相对当前上下文的改善；98.75% 区间 |
|---|---:|---:|
| 无；仅当前上下文 | 0.488029 | — |
| 原始公开历史统计 | 0.501381 | −0.013400 [−0.022900, −0.004262] |
| 历史 encoder 表示 | 0.495037 | −0.007027 [−0.013179, −0.001074] |
| attention 读出 | 0.495794 | −0.007774 [−0.012889, −0.002998] |
| 最终 decision state | 0.490346 | −0.002323 [−0.004354, −0.000407] |

当前上下文确实有预测力：只用训练集类别频率的测试 Brier 为 0.653996。加入历史特征后，这组有限数据的线性探针泛化变差；打乱的历史统计也变差。**这不是“历史有负信息”的证明**，更不能把线性探针失败等同于信息不存在。即使给自然轨迹探针追加真实身份，改善仍为 −0.000729 [−0.003134, +0.001624]。有限样本、当前上下文已解释主要行为、类别过粗或解码器能力不足，都尚未分开。

因此没有出现“原始历史明显有用 → encoder 保留 → 某一层突然丢失”的证据链；这次不能把风格信息损失精确判到公共 Transformer 的第几层。

### 对真实读出做干预，确认它很少左右选牌

这部分直接用 rollout 当时实际使用的 activation，避免把离线重编码误差当作网络结构效应。用**训练集**读出的加权平均向量，替换测试集每一个决策的真实读出，保留我方当前 query、合法候选和后续计算：

- 960 个测试决策，只有 **2 个首选动作改变（0.208%）**。
- 出牌概率平均 TV 为 **0.2238%**；中位数 0.0704%，95% 分位 0.9908%。
- 真实读出的平均向量范数约 1161.32，单条偏离平均的范数中位数仅 8.16。
- 私有 8-head attention 中，7 个 head 在 960 个决策上全部近似 one-hot；另一个为 959/960。这里是 u195450 的 private cross-attention，不是宣称公共四层 encoder 都饱和。
- 各 head 约 **94.4%–96.8%** 的落点在旧局，说明它确实读取旧局表示；“读旧局”和“利用对手风格改善动作”仍是两件事。
- 各 head 的 query 与平均方向余弦中位数为 **0.999917–0.999999**，仍接近固定查询方向。

读出被换成常量后动作几乎不变，是本轮最直接的弱利用证据。它与 [11 月 12 日的 Q/K、梯度诊断](history-root-cause-2026-11-12.md)相符，但不单独解释这些权重为何形成。未对主线加归一化或改变 reward。

## 5. 数值与工具修正，2026-11-13

保留失败版本及原始输入；以下问题均没有通过删异常样本解决。

1. `PublicTap` 原先只拦截事件列表接口，新的 batch drain 会绕过它。新诊断使用 `DiagnosticStore` 子类，让已有训练采集器走公开事件接口；训练代码不变。测试验证公开 stream 完全一致。加 native taps 前后，16 个块的全部公开轨迹文件 SHA 也完全一致。
2. 原方案从 raw prefix 离线重算各层。5,119 个有标签样本里，**1 个**出现超出 `1e-4` 的 log-prob 差：最大 0.02953，概率 TV 0.1704%，首选不变。复现的缓存/重编码 memory 最大差约 `9.09e-6`，该决策一个 head 的前两名分差仅约 0.187；大尺度、接近并列的注意力对微小数值差敏感。
3. 改为直接记录实际 cached inference 的 query、memory pool、reader、state，再做分析和常量读出干预。离线重编码只用于本轮对照和描述性 attention 统计，异常保留并标记；960 个 attention 样本中有一个重算 reader 不一致。原生 state 到动作的复算均通过验证。
4. 这**限定了**此前 24 次 CPU cache 检查通过的外推范围，不推翻当时 24 个样本的结果。当前没有发现缓存把历史丢弃或错误复用；也不能再把小样本 parity 当作全输入严格等价。本轮未测试当前 GPU 全链路数值。

## 6. 可以与不可以得出的判断

可以说：当前池有行为差异；本轮历史观察者未恢复可用身份后验；独立残局评价没有确认身份/历史回报收益；实际历史读出近似常量，最终出牌对其变化反应很弱。

还不能说：历史在理论上没有额外信息、模型已经学出了“历史无用”的最优策略、整个 encoder 没学、唯一根因是稀疏奖励，或归一化必然改善棋力。信息可识别性和决策价值两个门槛尚未通过，不能凭这轮负结果直接批准主线训练改造。

后续若继续诊断，应先提高独立选招估值稳定性，并提高公开历史观察者的辨识能力；不能只增加 PPO 训练时长、让小规模探针继续过拟合，或把 attention 变得敏感当成已经能多赢。
