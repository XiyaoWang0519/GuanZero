# u195450 历史事实解码与读取模块可学习性 — 2026-11-14

状态：已完成冻结分层解码，以及独立读取模块的监督训练对照。用户授权复用 u195450 和现成 filtered 对局，检查各层能否恢复历史答案，再比较原结构与 Q/K 归一化能否学会；要求不动主线。

**关键新证据：最终公共 encoder 的 token 表示仍能恢复这组历史事实（平衡准确率 95.31%），原生 attention 读出和最终 state 的探针却接近 50%。不能把平均池化探针的失败解释成 encoder 已经丢掉历史。** 在本轮有限的、冻结 encoder/query 的读取模块训练中，原结构为 50.05%，Q/K 归一化为 51.67%，差异区间跨零。归一化明显改善了一部分 Q/K 梯度，但没有在这套协议下形成可靠的历史事实读取器。

这定位的是**历史信息保留与读取/汇聚之间的缺口**，不是对手风格已经学会、胜率已提高、唯一根因已确定，或某种结构永远学不会的证明。一个归一化训练种子还出现新诊断头失活，限制了对学习失败的结构性归因。

## 1. 身份、数据和边界

- 被测 actor：u195450，SHA-256 `e4a3c989e01ca3f83665bca83c82897dc045e52bb20c5143a86fe27b1a9fd3c2`。
- 复用 [11 月 13 日诊断](filtered-history-diagnosis-2026-11-13.md)的 1,280 场 filtered 对局，来自封存的 u196664 population、全部 20 个 eligible snapshots。没有采集新比赛，也没有将池冒充为持续更新的最新池。
- 每场只取第 4 轮开头原协议 threshold=0 的首个我方非强制决策。上一局指第 3 轮，即零基 round_index=2。
- 问题：相对我方座位 +1、+3 的两名对手，上一局是否出过炸弹（含同花顺、四王）、对子、三带二、顺子、三连对、钢板。每场 12 个二元答案。
- 标签只读取相应座位、上一局、Play 阶段的公开 action type。当前局、我方/队友动作、贡还事件不计入答案。拒绝私有贡牌标志；没有读取对手手牌、合法集或 forced 标记。
- 按原始种子组沿用 **800 场训练、160 场验证、320 场测试**；相同牌种子的两种队伍方位不拆开。测试为 160 个独立牌种子组。
- 按原池的条件 snapshot 权重评分（16 个 archive 各 0.03125，4 个 recent 各 0.125）。题目只按训练集正例比例 5%–95% 检查资格，本次 12 题全部通过，未按测试结果筛题。

炸弹、对子等出现率不均，因此主要指标是**每题先平均正例、负例准确率，再对 12 题平均的平衡准确率**。恒定猜“有”或“没有”的基线都是 50%；不是普通准确率。每个配置使用三个初始化种子，结果为三个模型指标的平均，不是把三个模型当成三倍测试样本。

## 2. 冻结各层：先平均与逐 token 解码得到不同结论

### 平均池化探针

为每个目标座位，从上一局相应公开 token 取表示的均值，再拼接。分别取 public embedding、四层 encoder 和最终 stream norm。读取输出与最终 state 使用原 rollout 保存的 native activation。

所有分层探针共同接收固定的当前上下文（我方 query 和只编码本局的 state），再接最多 256 维的待测特征；补零保持输入宽度为 512。诊断头为 `512 → 64 ReLU → 12`，训练集标准化，1,000 步、batch 64、Adam 0.001、三个种子，验证集 balanced BCE 每 100 步选 checkpoint，包含第 0 步。encoder 和原 actor 全部冻结。

### 为什么补充逐 token 解码

第一轮训练/验证曲线显示平均池化后的晚层特征难以泛化。但池化本身可能损失信息，因此在读取测试集结果之前封存了 `token-protocol.json`：给每个冻结 token 表示训练一个公开牌型分类头，再按预测牌型确定性汇总同样的 12 个答案。

共 55,661 个上一局对手公开 Play token，按所属比赛划分为 34,738 / 6,918 / 14,005 个训练/验证/测试 token。**token 没有被随机分到不同 split。** 每层使用 `128 → 64 ReLU → 11 types`，三个种子、1,000 步、batch 256、Adam 0.001，验证 token CE 选 checkpoint。分类后取每个 token 的 argmax，再检查该座位是否出现过相应牌型，不针对测试结果调汇总阈值。

逐 token 方案使用更细的监督，并获得明确的公开局号/座位索引和确定性汇总器。它是检查 memory bank 中信息是否仍存在的更强解码器，**不是与原生 policy reader 等容量、等监督的棋力比较**。分类头能恢复输入公开牌型，也不表示模型已形成对手风格概念。

### 测试结果

| 冻结表示 | 先平均 token 再解码 | 逐 token 解码，再汇总同样的历史答案 |
|---|---:|---:|
| 原始公开动作计数 | 90.56% | 确定性读取真实公开事件：100% |
| public embedding | 64.56% | 100.00% |
| encoder 第 1 层 | 57.31% | 99.99% |
| encoder 第 2 层 | 57.22% | 99.95% |
| encoder 第 3 层 | 58.70% | 99.85% |
| encoder 第 4 层 | 49.58% | 94.16% |
| 最终 stream norm | 50.06% | **95.31% [94.23%, 96.46%]** |
| 原生 private attention 读出 | **50.53% [49.34%, 51.77%]** | — |
| 原生最终 decision state | 50.46% | — |
| 只看当前上下文 | 51.08% | — |

方括号是按测试牌种子组 bootstrap 的描述性 95% 区间。完整逐题/逐种子指标见机器记录。最后 stream norm 的公开 token 牌型普通准确率为 97.50%；表中 95.31% 是汇总后的**历史事实平衡准确率**，两者不能混用。测试中四王牌型仅 1 个，分类级宏平均受到这个罕见类别影响，不将它解释为稳定的单类能力估计。

可以确认：这些历史事实需要的信息在最后的 token bank 中仍可被解码。**第 4 层池化结果接近随机，不足以说明信息在第 4 层消失**；逐 token 方案直接反驳了这种解释。原生读出没有为同一事实探针提供超过当前上下文的可靠增益：差 −0.56 pp，95% 区间 [−1.78, +0.73]。

## 3. 读取模块监督训练：Q/K 归一化尚未产生可靠学习收益

固定 encoder、private query、原融合与动作头。仅复制 `q_proj`、`kv_proj` 的 K/V 两半、`out_proj`，加上新的诊断头；原 actor 对象和 checkpoint 文件不变。诊断头接在 reader 输出后，不经原出牌头，也不训练 PPO。

| 组 | 可更新内容 |
|---|---|
| frozen | 原 reader 固定，仅训练诊断头 |
| native | 原 reader 的 Q/K/V/out + 诊断头 |
| norm_frozen | 加无 affine 参数的 per-head Q/K LayerNorm，reader 固定，仅训练诊断头 |
| norm | 相同 Q/K LayerNorm，更新 reader 的 Q/K/V/out + 诊断头 |

Q/K 归一化不重置旧投影；它改变了前向函数，不是保函数迁移。两种结构使用同样的诊断头架构 `128 → 64 ReLU → 12`、相同种子初始化和 minibatch 索引。输入中心/尺度只由各组训练集初始 reader 输出计算。每组每种子试 0.0003 / 0.001 两个学习率，各 2,000 步、batch 32；Adam 无 weight decay，梯度 clip 1。每 200 步按验证 balanced BCE 选择 checkpoint，再按验证 loss 选学习率。共 24 次固定预算运行；所有选择封存之后才评分测试集。

| 已封存的组 | 测试平衡准确率；95% 区间 | 仅本局输入 | 打乱旧局、保留本局与当前 query |
|---|---:|---:|---:|
| frozen | 49.48% [47.99%, 51.05%] | 50.09% | 49.84% |
| native | **50.05% [48.92%, 51.08%]** | 50.62% | 50.09% |
| norm_frozen | 50.85% [49.08%, 52.53%] | 50.69% | 49.55% |
| norm | **51.67% [50.43%, 52.85%]** | 49.58% | 50.92% |

主要比较 norm − native 为 **+1.62 pp，配对 95% 区间 [−0.01, +3.23]**；没有可靠确立改善。norm − norm_frozen 为 +0.82 pp [−0.61, +2.26]，也未确认读取模块训练本身贡献了增益。三个 norm 种子的测试结果为 49.94%、50.99%、54.07%，不能将平均值的小幅提升写成稳定学会。

原结构三个种子按验证集最终都选择第 0 步。它确实完成了 2,000 步训练，并不是没有执行：所选学习率下末步训练 balanced BCE 降到约 0.515–0.520，验证却升至 0.806–0.831。这是本设置下训练拟合不能泛化的结果；评测保留验证集选择规则，没有用测试成绩挑训练步数。

### 梯度和诊断头限制

六个 native 运行合计记录 174 个预定梯度采样点，Q/K 非零仅 **6/174（3.45%）**，V/out 为 174/174。六个 norm 运行中 Q/K 非零为 **121/174（69.54%）**，绝对梯度也较大。这里是记录的采样点，不是对所有更新步或所有主线 batch 的断言。

归一化各选中 checkpoint 之前记录的 Q/K 梯度均非零，且相应投影发生了实际变化。但优化并不干净：norm seed 72 的选中模型在训练样本上有 **65.75%** 的输入使诊断头全部 64 个 ReLU 单元关闭；另外两个选中 norm 模型没有整行全部关闭，激活比例也偏低。该问题发生在本次新诊断头中，**不能直接归到主线动作头**。

因此本轮只能说：在这套固定监督训练协议下，单独 Q/K 归一化没有可靠教会事实读取。它不能排除其它学习率、头部参数化、更多数据、可训练 query/encoder 或新的读取方式能成功。测试结果出来后没有继续调参、延长训练或用同一测试集挑一个“成功修复”。

## 4. 如何理解它对根因的推进

1. **信息保留环节：有明确正证据。** 最终 encoder token bank 可以恢复这些已发生的公开事实，所以“历史整体未进入模型/全部被遗忘”不符合这组证据。
2. **读取与汇聚环节：有明确的使用缺口。** 合适的逐 token 解码能恢复答案，平均池化和原生 reader 都做得很差。重点应是怎样按目标读取、汇聚多条历史，以及当前 query/投影的优化；不能简单将失败指定为公共第 4 层。
3. **奖励稀疏不是已证实的唯一解释。** 本轮直接提供事实标签，绕过了比赛输赢的延迟反馈，仍未训练出可靠 reader。但数据量、冻结范围、监督目标与诊断头优化均有限，不能据此排除奖励在真实 RL 中的作用。
4. **Q/K 尺度修正不是已验证的完整修复。** 梯度恢复与成功检索、事实泛化、实际胜率改善是不同验收条件。这轮只前进到更清楚的信息/读取诊断，不批准主线采用归一化。

题目不证明这些事实值得用于某个当前动作，更不证明对手习惯存在可利用价值。棋力与历史的策略价值仍以 [11 月 13 日报告](filtered-history-diagnosis-2026-11-13.md)的未决结论为准。

## 5. 数值、统计与验证

- 分层 encoder 重建逐项与原 `encode_batch` 一致。此前已知的 1 个 cached reader / 重编码数值例外仍在：1280 个当前样本中最大 reader 差 0.6788；原生 reader/state 探针使用保存的 native activation，重算版另报，本次二者最终指标相同。没有删异常样本。
- 读取模块训练在相同重编码 memory 和 CPU math SDPA 上比较；Q/K 用 FP32，无模型量化。
- 旧局负对照取同 split、同队伍方位、不同牌种子组的 donor，按当前 observer 旋转座位，将 donor 旧局前缀与 receiver 原本局后缀拼接，当前 query 不变。旧前缀长度随 donor 改变，这不是等长因果干预；不把负对照差值解释为纯风格或纯内容价值。冻结分层探针另做特征向量置换，二者不同。
- 区间使用 5,000 次 bootstrap：在每个固定对手类型内，重采样其 8 个测试种子组；两种队伍方位保持成组。三个优化种子先平均得分，未当作新的测试样本。区间描述当前已训练模型的测试集不确定性，不覆盖完整的优化种子总体不确定性。除 norm − native 外，其余多项层间/对照比较是描述性分析，未作多重比较确认。
- 用独立保存的 `public.npz` 事件日志重新生成全部 **1,280 × 12** 个答案，与 sample-token 标签逐项一致。token split 与所属 match split 逐项一致。
- **23 个相关测试通过**：标签的局/座位/阶段边界，拒绝私有标志，reader 与 owning attention 一致，padding 不可见，副本梯度/更新不污染原模型，旧局替换保持当前后缀，平衡指标不奖励多数类猜测，逐 token 汇总，以及种子组 bootstrap 边界。
- u195450 checkpoint、原始 sample 文件和已有训练实现 SHA 前后相同；`train/`、`cpp/` 未改。本轮只有本地诊断模型副本更新，没有远端操作或主线训练干预。
