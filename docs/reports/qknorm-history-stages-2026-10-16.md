# 冻结历史编码、读取与出牌状态的分层诊断（2026-10-16）

状态：**1,024 场冻结重放和分层读数完成：编码与实际历史读取都含可预测公开行为的线索；线索的线性可读性在 query 融合及归一化后显著变弱。支持后段弱使用的解释，不证明信息彻底丢失或某一模块有 bug。** 用户授权离线判断“信息没记住”还是“出牌没用上”。
不更新 actor、critic 或辅助头，不创建优化器，不训练策略，不改主线。

## 问题

[等长替换](qknorm-history-swap-2026-10-16.md)已发现弱内容敏感度：保留当前
局面、长度、位置和全部 round/phase 标签，只改旧公开 token，动作分布平均
TV 约 0.40%/0.45%，两端点各只有两次首选翻转。但这个结果不区分历史编码器
本身缺信息，还是历史读取与策略映射没有使用已存在的信息。

本次用相同的离线任务检查不同层的**可读出信息**，不把激活变化等同于有用信息，
也不把“线性统计探针没读出来”直接判为信息彻底丢失。

## 样本、表示和标签

- 两个冻结端点仍为隔离短 PPO 的 control/qk-both 与 norm16，SHA 与上次一致。
- 重放已有多样对手池的全部 16×32 场 FULL，每端点 512 场。所有比赛记录须
  逐项等于已有 FULL 结果，采集不得改变真实动作或随机数流。
- 每场只取第 4 局 learner 第一个至少两合法动作的 PLAY 决策。前三局已经
  完整结束；只编码该决策已见的前缀，不使用第四局后续行动。
- 前 8 waves（每端点 256 场）校准统计读数，后 8 waves（256 场、128 seed
  簇）独立核验。同 seed 的两队换座始终属于同一划分。
- 基线是当前私有 query、只保留本局时的历史读取向量，以及前三局各自公开
  token 数和当前局前缀长度，避免把简单的牌局长度变化当作新增内容收益。
- 历史编码：旧 token 的最终编码均值、旧对手 token 的均值、最后一个旧
  token，均不含 BOS 或当前局 token。编码有因果掩码，旧 token 看不到后续。
- 历史读取：真实 FULL attended 向量（经 out_proj），及 FULL−ROUND 差。
- 出牌状态：真实最终 decision state，及 FULL−ROUND 差。用原生函数逐项
  核对手工取出的中间状态，原历史新编码与真实 KV 的 logp 误差必须 <1e−4。
- 公开正对照：前三局对手的 pass/single/bomb/other 频率，带固定 .5 平滑；
  tribute 不进入频率。不得读取 hidden_counts、forced 或其他座位私有输入。

## 固定统计校准与“有用”的含义

统计读数只在旧记录上做一次**闭式 ridge 计算**，不是给模型增加训练目标，
不会把读数接回 actor，也不更新神经网络。用四类冻结对手标签作校准标签，
held-out 的真实对手身份不进入预测器；只用于事后核验和选择公开评分标签。
每个层都用同一套固定参数：训练集均值/标准差，标准差下限 .01，正则 N×1，
先验截距，四类预测分数截到至少 1e−4 后归一化，没有超参数搜索。

每层都比较“当前基线＋该层”和“当前基线＋打乱该层”。打乱按完整 seed 簇
跨比赛进行，保留两队换座位置，无同 seed 供体；训练和测试独立打乱。另报告
纯当前基线，避免靠增加维数、重复表示或正则化差异宣称读取出新增信息。

在核验集评分前补充预定同宽度单独读数：每个层不用当前基线拼接，单独校准
同一 ridge；旧记忆对照均匀先验和打乱记忆，128 维 FULL reader/state 对照
对应 128 维 ROUND reader/state。这用于检查信息可用性，避免将重复当前表示
导致的有效正则变化误称为新增信息。所有结果均保留；补充报告 99% 描述区间，
仍是探索性定位而非多假设校正后的修复验收。

任务包括：

1. 能否识别四个已知冻结对手（机会准确率 25%），同时报告四类 Brier。
2. 更关键的是，读出的对手概率能否帮助预测**相同牌、相同公开起点**下的出牌
   类别：重用已独立保存的 256 道首出题，每模型 32 次公开参考答案、32 次
   评分答案。用 inferred posterior 混合四个参考分布，评分只看公开答案。

这是沿用之前 same-card 实验的诊断性条件化：共享参考分布不可能作为在线
私牌特征给 actor。它测稳定风格信息能否帮助预测公开行为，不测牌力、奖励、
后续复杂局面适应或 actor 会不会做出正确行动。

每端点 128 个测试 seed 簇（两队换座保留），按四个对手分层 bootstrap 10,000
次，并交叉重采样 256 道公开问题。所有预定层、基线与打乱对照都报告，分层
比较是探索性诊断，不挑最好的一个宣布修复成功。

## 结果

### 覆盖与验证

16 个 worker 全部 exit 0，采集用时 **177.88 秒**，本地 CPU。
两个端点各 512 场 FULL、各 512 个第 4 局决策全部重放一致，未丢样本。
每端点 256 校准、256 核验，128 个独立核验 seed 簇。所有中间向量和概率有限。
原生 decision state 与手工 tap **逐位一致**；后续融合复算与保存的 state 最大
误差也为 **0**。新编码与真实 KV 最大 logp 误差 control **4.1962e−5**、
norm16 **3.8147e−5**，均通过原定 1e−4 门槛。

越好，跨两端点使用同样的题、参考答案和评分答案。

整个 encoder 遗忘：此架构保留全部 token 的 KV，本来就不要求最后一 token
成为全部历史的单一摘要。本实验的汇聚也是额外离线观察，不是 actor 实际
增加了一个 pooling 模块。

### 真实读取也读到了，最终 state 未显示可靠的额外帮助

同宽度 FULL−ROUND 的独立问题误差改善：

| reader | +0.009649 [+0.005379, +0.014153] | +0.008167 [+0.003687, +0.012969] |
| 最终 state | −0.000116 [−0.000510, +0.000282] | −0.000131 [−0.000470, +0.000208] |

最终 state 虽然能优于“打乱整个 state”，但 ROUND state 已经提供同样量级的

最终 state 的区间包含零也不证明等效或完全不用历史。

### 探索性拆解：从哪一步开始难读

看到上述结果后，额外用**已保存的 query 和 reader**复算融合，不再打比赛、
不更新任何权重。各中间层仍用同一个固定 ridge、同一校准/核验划分和独立
公开题评分。这一步是事后探索性定位，不冒充预注册模块根因检验。

| 位置 | control 的 FULL−ROUND 问题误差改善（95% CI） | norm16 的改善（95% CI） |
|---|---:|---:|
| 刚读出的 history reader | +0.009649 [+0.005379, +0.014153] | +0.008167 [+0.003687, +0.012969] |
| query＋reader 相加后 | +0.003579 [+0.000694, +0.006500] | +0.003548 [+0.000693, +0.006558] |
| attention_norm 后 | −0.000433 [−0.001121, +0.000228] | −0.000609 [−0.001303, +0.000064] |
| 前馈残差后 | −0.000083 [−0.000437, +0.000279] | −0.000143 [−0.000457, +0.000171] |
| output_norm 后 | −0.000116 [−0.000510, +0.000282] | −0.000131 [−0.000470, +0.000208] |

相对校准均值的核验样本变化 RMS 中位数，query 是 **31.13 / 30.38**，
reader 是 **0.377 / 0.459**。这里比较的是同一相加坐标中的跨样本变化，
不是两个 raw norm 大小就断言根因；它支持“内容变化较小、混入当前信息后
难以利用”的嫌疑。attention_norm 后只有 1/2 列标准差落在 .01 下限，
最终 state 为 0/0 列，所以不是最终表示全部被读数的缩放下限截平。

**最值得怀疑的位置是 query 融合、归一化及其后续策略路径。** 这不证明
LayerNorm 实现错误、所有有用信息都被抹掉，或简单放大 reader 就能提高胜率。
非线性变换可能让线性读数失灵，必须保留这个替代解释。

### 人话结论

**更像是记住了、也读到了，但出牌时没充分用上。** 编码器里能读出的线索
能帮助预测独立公开出牌，真实 reader 也有；合并当前手牌信息之后，这类线索
变得明显难读，最终出牌状态未显示可靠的额外帮助。结合之前等长替换只引起
约 0.4% 的概率重分配，当前证据把疑点收窄到了后段融合和策略使用，不能再
简单归因于历史编码器完全没记住，也不能宣布已经找到并修好了架构问题。

没有训练、生产源码变化、长跑或自动后继实验。闭式统计读数只存在于本地
分析，不接回模型。两端点的差异不能解释为 norm16 修复有效；它们轨迹不同，
本次不做棋力或修复收益比较。与早前固定 count-table 探针采用了不同解码器，
误差改善数值不能当作模型又学好了多少。


## 判读边界

- 编码可读出有用信号、读取端读不出：支持瓶颈更靠近读取，但线性探针可能
  漏掉非线性信息，不能证明读取端绝对没有信息。
- 读取端乃至最终 state 都能读出，动作却只有微弱反应：更支持信息已经送到
  出牌路径，弱使用可能在策略映射或学习信号上；不证明每个局面都应当改选。
- 编码本身读不出：只能说这几种固定汇聚与线性读数没找到信息，不能断言
  encoder 没记住。正对照若也失败，须先承认诊断检出能力不足。
- 当前基线减轻牌局/手牌影响，不能穷尽所有非线性混杂。已知四模型的身份与
  打法、牌力混在一起；不是纯风格因果隔离。一条训练谱系、一个训练 seed，
  不支持推广到所有对手。独立道题是首出题，不代表中后盘所有信息价值。
