# 公开历史的局部决策价值 CPU 筛查

日期：2026-10-17。状态：固定预算已完成，未建立决策收益。用户授权实现并运行本地 CPU 决策价值试验；本轮没有策略训练或主线行为变更。

2026-10-17 后续：[扩大配牌样本和独立重测](history-decision-stability-2026-10-17.md)完成 40,960 局；估值噪声下降，但排序仍未稳定，身份与公开历史的独立收益区间仍跨零。以下保留首轮 6/12 副配牌的历史结果。

## 结果与下一步判断

**8 个独立手牌信息集、4 种冻结对手、2,880 局独立评分分支，没有建立“知道对手后换动作能增加收益”的验收任务。** 真实身份选动作的独立评价增益为 −0.00521，探索性根节点 bootstrap 95% 区间为 [−0.14844,+0.10417]，单位是 PPO 本局团队 `seat_return`。公开历史 posterior 的 32 次选择全部等于先验方案；当前 actor 在这些历史下的 greedy 首选也全部等于其 ROUND 首选。

这不是身份信息没有价值的证明。每种类型、每个动作只有 6 副选动作配牌和 12 副评价配牌，真实身份方案使用的是有噪声的 Q 估计。本轮没有得到可复现的正收益任务，因此不进入 native/history4 PPO 适应对照，也不追加 norm16 训练。

## 对上一份综合报告的解释修正

[综合报告](history-utilization-investigation-summary-2026-10-17.md)中的分层读数支持后段的线性可读性较弱，尚不能把融合结构确定为根因。身份线索可以通过当前局面与历史的非线性交互参与决策；最终 state 难以线性解码身份，不等于动作所需的信息已经丢失。query 近共线本身也不是修复失败的充分条件。

固定校准均值下，`history4` 不扩大原策略函数集合。实际实现为 `r=Wu+b`，而 `q+rbar+4*(r-rbar)=q+4Wu+4b−3rbar`，可以完全吸收到带 bias 的 `out_proj`。真实冻结 control 端点上，以 64 行合成输入检查投影及后续层，最大 state 误差 1.669e−6，通过 1e−5 门槛；未修改权重。如果以后 history4 有收益，应先解释为初始尺度或优化路径改善。这个推导不适用于 postnorm4。

因此，“跨局公开历史完全没有价值已被反驳”应收紧为“在已测四对手池中，完全没有新增预测信息的解释已被反驳”。本轮直接检查的是下一层决策收益。原 control 的完整比赛弱正向信号仍保留；这里没有重跑或推翻原 FULL/ROUND 比赛。

## 任务和固定预算

这是“观察旧行为后重新开评分局”的冻结诊断。观察历史来自原多样池公开记录的前三局；评分局独立重新发牌，从级数 2、seat 0 首出开始。它不构成积分与进贡自然衔接的完整比赛。

| 项目 | 固定设置 |
|---|---|
| 评分 actor 和队友 | 短 PPO control 端点 u94608，即原 qk-both 继续 120 updates 的端点 |
| 对手类型 z | u2623、u20264、u35588、u86800；两个对手座位使用同一类型 |
| 自己与队友座位 | 0 与 2；所有信息集均固定 seat 0 首出 |
| 独立信息集 | 8 个新发牌 seed；每处固定自己的 27 张牌与合法观测 |
| 类型先验 | 四类均匀；新评分局自己的牌、座位、级数与类型独立 |
| 候选动作 | 至多 5 个；先包含 ROUND 与四份 FULL 历史下的全部 greedy 首选，再按 ROUND 概率填满 |
| 选动作配牌 | 每处 6 副其余三家的合法配牌；所有类型和候选共用这些样本 |
| 独立评价配牌 | 每处另取 12 副；所有类型和候选配对使用 |
| continuation | 自己与队友用同一冻结 control；对手用类型 z 的冻结 Transformer；所有座位均只看评分局历史，temperature 1 采样 |
| 初始动作 | 先验 Q 选择、真实身份 Q 选择、公开历史 posterior Q 选择、native actor greedy FULL/ROUND |
| 收益 | `RoundResult.seat_return[0]`，与 PPO 本局团队收益语义一致 |
| 预算 | 8×4×5×(6+12)=2,880 个评分局分支；全部完成，无剔除 |

公开历史只参与初始动作选择，之后统一使用本局历史，使 `Q_z(o,a)` 的 continuation 不随观察历史变化。这里的当前 actor 比较明确限定为 **greedy 初始动作**；continuation 使用随机采样。没有估计 actor 初始动作完整 softmax 的期望收益。

完整 rollout 的墙钟合计约 39.12 秒，不含模型加载、历史统计校准和后处理；这是本次记录，未作吞吐对照。

## 信息边界与采样顺序

每处固定 actor 可见的手牌、座位、公开起点和候选动作。引擎 `determinize_uniform(0,seed)` 从与该信息相容的剩余双副牌中重新分配三家私牌，原始实际私牌不参与选动作。新评分局独立于旧观察牌局，因此不用根据旧局动作反推新局私牌。

对每个类型和候选，先平均隐藏世界：

`Qhat[z,a] = mean_world return[z,a,world]`。

再用均匀先验、真实身份 one-hot 或公开历史 posterior 对类型加权并取 argmax。没有逐副私牌取最大值后再平均。候选构造只用 actor 合法输入下的概率，不用 rollout 回报或类型 Q 排序。

独立评价对所有候选使用新配牌，计算已经由选动作数据确定的选择之收益。虽然评价表包含其他候选，报告函数不会根据它们重新选动作。48 个选动作 world seeds 与 96 个评价 world seeds 的集合不相交。

模拟器和各座位的冻结 actor 可以分别访问它们需要的实际私牌与自己的观测；身份、其他座位私牌和 `hidden_counts` 不进入根节点 actor 或 posterior。每条分支开始时逐行断言根节点 obs 与完整候选张量等于原信息集。独立测试进一步验证：先改变原始真实私牌，再用相同 seed 重采样，仍得到相同的隐藏世界。

每条分支只取第一局的实际完整回报。完成首局后停止该 slot 的模型推理；若 512 个 vector steps 内未全部完成，整批报错，不能剔除慢局。公共缓存保留本局事件，冻结模型没有 optimizer 或参数更新。

## 公开历史 posterior

复用既有 count-table 方法及其固定温度：在多样池 wave 00–07 的 512 场公开数据上校准；按 pass/single/bomb/other 和首出/跟牌统计前三局行为，用 `softmax(history_logits)` 形成类型概率。标签仅用于校准分组和评价，不作为 held-out 特征。

本轮历史固定取 wave 12–13：对第 i 个信息集，用 `wave=12+i//4`、`env=(i%4)*8+2*z`，共 32 份前三局历史，均来自原 control 一侧、team 0。历史只依调度和公开事件构造，不按评分回报筛选。原历史集已用于此前探索，因此本轮独立的是评分配牌与回报，不应把这些历史再称为全新确认集。

这批历史的类型 argmax 准确率为 16/32，即 50%；posterior 最大概率平均只有 26.97%，范围为 25.33%–31.50%。平均熵 1.3831，接近均匀四类的 ln(4)=1.3863。**身份 argmax 有些预测力，但后验概率非常接近先验。** 这些概率在本轮估值表上没有改变动作。它们不是 reader 中全部可利用信息的最优解码，也未在本轮重新调温度或改预测器。

## 独立评价收益

以下区间以 8 个信息集为簇、配对重采样 10,000 次，均为探索性 95% bootstrap 区间。四类型在每个信息集内等权；没有把每局或每个动作当成独立研究样本。

| 初始选择方法 | 独立评价平均回报 | 相对先验 Q 方案的增益 | 探索性 95% 区间 |
|---|---:|---:|---|
| 先验 Q 方案 | 1.02083 | 0 | 参照 |
| 真实身份 Q 方案 | 1.01563 | −0.00521 | [−0.14844,+0.10417] |
| 公开历史 posterior Q 方案 | 1.02083 | 0 | 同一动作，逐样本完全相同 |
| 当前 actor greedy ROUND | 1.18750 | +0.16667 | [−0.02083,+0.37507] |
| 当前 actor greedy FULL | 1.18750 | +0.16667 | [−0.02083,+0.37507] |

真实身份 Q 方案在 32 个类型条件中有 15 次改变先验动作；posterior 改变 0 次。FULL actor 相对 ROUND actor 首选改变 0/32，但整个动作分布 TV 平均为 6.410%、最大 12.622%。因此不能写成“actor 完全不响应历史”。这里 FULL/ROUND 同时改变历史长度和位置，也不能把这个 TV 与此前等长内容替换的约 0.4% 直接比较。

posterior 和 actor FULL−ROUND 的零差，是本轮固定决策规则选了相同动作造成的恒等结果；不能把由这些零值产生的 [0,0] bootstrap 区间当成“历史价值被精确界定为零”。

选动作数据上的 plug-in 身份价值平均为 **+0.20833**；独立评价后变成 **−0.00521**。理论上使用精确 Q 的真实身份价值非负，但这里使用 6 个世界的估计值来选动作，会产生选择误差。这个反差说明必须保留独立评价；它没有证明理论身份价值为负。

当前 actor 也高于这个小样本 Q 先验方案的点估计，进一步说明该 planner 尚不是可靠上界。真实身份方案减 actor FULL 的探索性差值为 −0.17188，区间 [−0.33333,−0.00260]；这是本轮固定规则的附加描述，没有多比较校正，不能推广为一般的 actor 优势。

## 局限和研究优先级

本次没有构造出适合验收 PPO 历史利用的稳定正收益题。最直接的限制是 Q 估计太粗，posterior 又很接近均匀。8 个开局手牌、每处 5 个候选、固定 level 2 与首出，以及只通过一次动作适应对手，都限制了检验范围。40 个候选含 Single 11、Pair 4、FullHouse 10、Straight 12、Plate 2、Tube 1，未覆盖任意合法反制策略。

即使本轮没有增益，也不能区分真实身份价值小、候选不足、Q 选择误差或固定 continuation 无法执行多步反制。区间同时受少量信息集限制；本轮不是对 3–4 pp 完整比赛胜率差的功效设计，PPO 回报单位也不能换算成 match win。

优先级保持为先建立决策价值，再检查 PPO 是否能兑现。下一次若要增加预算，应先固定一个能评估 Q 稳定性的方案，例如独立重复估值的动作排序一致性，或在与正式评价分离的筛选集上选择高影响局面。任何根据本轮收益挑出的局面，都需要新的确认数据。当前不自动扩大样本、不改 next-token 权重、不启动 native/history4 或 norm16 训练。
