# u184140 / u195450 历史利用根因诊断 — 2026-11-12

2026-11-13 补充：[当前 filtered 池的大样本诊断](filtered-history-diagnosis-2026-11-13.md)
在 5,119 个有标签决策中发现 1 个 CPU cache / 重编码数值差异（最大概率 TV 0.1704%，
首选不变），后续采用原生 cached activation。本报告的 24 次 parity 检查记录保留，
但不能外推为所有输入严格等价；新版也复现了读出弱利用。

状态：已完成冻结权重的 CPU 前向、activation 干预、backward-only 和源码核对。
没有 optimizer step、主线训练修改或新棋力评测。用户要求深入解释历史替换影响很小，
以及匹配历史为何没有在上一轮比赛中胜过错配历史。

**已定位的直接机制：私有 cross-attention 的 Q/K 选择在被测输入上硬饱和，
query 方向几乎不随当前决策变化；读出又主要表现为一个很大的近似常量。
历史确实进入模型，但其变化很少影响最终选牌。** 这不等于整个历史编码器停止学习。
首次形成这种权重几何的训练原因尚未唯一定位，不能把它全部归因于 filtered、KV cache
或历史 CUDA 故障。

## 2. KV / 训练管线没有发现的故障

只读获取了 Velocity 上实际部署的 `history_model.py`、`history_ppo.py`、
`history_population.py`，与 u195450 内嵌 source seal 的 SHA-256 全部匹配。
本地 `history_rollout.py`、`history_attention.py`、`history_inference.py` 也与 seal 匹配。
完整摘要和逐文件 hash 在 [机器可读记录](data/history-root-cause-2026-11-12.json)。

- 采集时的 KV cache 是冻结 rollout 区间的加速缓存，公开事件仍保存在按 `(env, match)`
  索引的原始 stream 中。换局不会清除同场旧事件；`window=0` 不截断旧局。
- PPO 的 `minibatch_loss` 调用 `training_batch`，再执行 `decision_states(None, ...)`，
  从原始 token 重新编码并保留 autograd。没有把 rollout 的 detached KV 直接当作
  不可训练特征送进学习。每个决策按自身 prefix 屏蔽未来事件。
- learner cache 在学习前被清除，下一次 rollout 按更新后的权重重建。
- 对 u195450 的 24 次缓存/直接重编码检查，全部候选概率差为 **0**，首选全部相同。
  最大编码浮点差为 `3.31e-6`。换成同 key 的新 stream 时，cache rebuild 计数由 1
  变为 2。没有发现“历史换了但旧缓存没失效”的问题。
- 同样 24 次检查，本地默认模型和从远端下载的部署模型产生的 decision state 差为 **0**。
  模型参数逐位相同。不能将本地可选 split fusion 误认为主线已启用。
- 对手快照按整场 match 分配、固定且 pinned；没有发现每一局随机换快照。
  identity=0 的 learner 席位会随 PPO 更新，不是整场冻结。
- 部署的 grad-enabled CUDA 私有注意力明确使用 math SDPA。这次没有实跑 GPU，
  不能把 CPU 检查称为当前 GPU paged kernel 的全链路验证。

因此，“训练喂了 KV”只说明有历史可供计算，不保证模型已学会选择和利用它。

## 3. 权重与 activation：选择器硬饱和

审计对象是把私有手牌/当前观察接到公开历史上的 **8 个 private cross-attention heads**，
不是宣称公共 Transformer 每层都出现同样问题。分数从实际 FP32 Q/K 用 FP64 重算；
未改动的两个 actor 均与原生 `decision_states` 完全一致。

| 测量 | u184140 | u195450 |
|---|---:|---:|
| 非空历史中 one-hot 的 head/决策比例 | 8 个 head 各 100% | 8 个 head 各 100% |
| 所有 head/决策中最小 top1−top2 分差 | 231.37 nats | 125.23 nats |
| 各 head 的 top1 分数绝对值中位数范围 | 7.96e5–3.91e7 | 6.69e5–3.83e7 |
| 各 head 的跨决策 Q 余弦中位数范围 | 0.999793–0.999998 | 0.999836–0.999998 |
| 用批内平均 Q 替代实际 Q，读取位置保持率 | 7 heads 100%，另一 head 99.956% | 7 heads 100%，另一 head 99.911% |
| 私有 query 范数中位数（按 minibatch 汇总） | 3440.90 | 3610.63 |
| Q 投影矩阵第一奇异方向的平方能量占比 | 97.849% | 97.795% |
| K 投影矩阵第一奇异方向的平方能量占比 | 90.202% | 89.854% |

u195450 的 Q 投影第一/第二奇异值是 236.48 / 20.17，K 是 198.39 / 37.83。
这是权重和实际输入共同形成的高度单方向查询：几乎不根据“现在这手牌需要什么信息”
改变读取方向。大尺度 QK 分差使 FP32 softmax 的其他位置下溢，选择退化成硬 argmax。
数学上 `dp_i/dz_j = p_i (delta_ij - p_j)`；精确 one-hot 时该局部 Jacobian 为零。

本样本 6 个 minibatch 中，两个 checkpoint 的 **每一个 Q/K head** 在策略 loss 和
outcome loss 下梯度范数都是精确 **0**。u195450 的 V、out_proj、encoder 和私有手牌路径
仍有非零梯度，例如策略 loss 下的中位范数：V `0.01653`、out_proj `0.04937`、
encoder 第 0 层 `0.00271`、private MLP `0.33922`。因此不能说整个网络“没学”。

同样不能说这些 Q/K 参数在所有训练样本上一直不动：u184140→u195450 的参数相对变化
分别为 **5.00% / 6.93%**，Adam 二阶矩没有衰减到旧 u86800 诊断的数值地板。
这次测到的是当前分布下的严重局部学习瓶颈，不是全部训练轨迹的零梯度证明。
编码器四层同期参数相对变化为 18.4%–19.8%，V 为 35.0%，out_proj 为 23.8%。

现在多数 head 确实读到旧局位置，早于当前局的落点比例为 78.5%–83.0%；
BOS 比例仅 0.044%–2.748%。不能套用旧 u86800“7 个 head 读 BOS”的结论。
但每场抽取 48 个决策，每个 head 的不同绝对落点数中位数只有 2–4。
选中的 token 本身经过因果编码，可能包含它之前的信息；硬选一个 token 并不等于只看一张牌。

### 直接干预验证

只在 u195450 副本里给投影后 Q/K 加 per-head LayerNorm：

- 2,256 个非空历史决策上，8 个 head 的 one-hot 比例全部由 100% 降为 **0%**。
- 所有 head、全部 6 批的 Q/K 策略梯度恢复为非零；总 Q/K 范数中位数
  分别为 `1.279e-5` / `1.988e-4`。
- Q 方向仍几乎相同，余弦中位数范围仍为 0.999835–0.999998。

这直接支持“尺度导致饱和，饱和堵住选择梯度”的机制；**不证明已学会按局面检索，
也不证明归一化后能提高棋力**。没有 optimizer step，原 actor 的权重 digest 前后相同。

## 4. 历史读出主要成为近似常量

在新采集的 1,953 个跨局决策上，u195450 的 out_proj 后读出向量：

- 全体平均向量范数：**1160.94**。
- 单次读出范数中位数：**1161.14**。
- 单次读出减去全体平均后的残差范数中位数：**6.71**，95% 分位 **14.14**。

分 head 投影到最终读出空间后：

| Head | 平均贡献向量范数 | 相对自身平均的残差范数中位数 |
|---|---:|---:|
| 0 | 463.01 | 2.33 |
| 4 | 385.60 | 1.58 |
| 6 | 287.54 | 1.56 |
| 其余 5 个 | 0.59–2.92 | 0.82–3.76 |

out_proj bias 范数只有 25.26，因此近似常量主要来自被投影的 head 输出，不能归结为
一个巨大的 bias 参数。以上是样本中的几何描述，不是各 head 的独立棋力贡献分解。

**因果替换：把 1,953 个决策各自的历史读出全部换成同一个平均向量，当前观察和候选不变。**
首选动作只改变 **4/1953**，策略 TV 均值 **0.1745%**、中位数 **0.0297%**、
95% 分位 **0.7978%**。保留一个常量并不等于移除整条历史路径；它验证的是
这批决策对读出中“随历史而变化的部分”的依赖很弱。

在 121 个固定局面的等长旧历史内容替换中，u195450 的逐阶段结果为：

| 量（各局面相对变化的均值） | 测量 |
|---|---:|
| 旧 token 编码变化 / 原旧编码范数 | 29.98% |
| out_proj 后读出变化 / 原读出范数 | 1.191% |
| 读出变化 / 私有 query 范数 | 0.417% |
| 相加后 attention_norm 输出变化 / 原输出范数 | 0.320% |
| 最终 decision state 变化 / 原 state 范数 | 0.446% |
| 最终策略 TV | 0.3364%，首选改变 0/121 |

TV 定义为全部合法动作概率绝对差之和的一半。不同层的相对范数不是同一个单位，
不能直接相除得到“信息丢失百分比”。但替换前后确实有编码变化，最终行为变化很小。
这尚未测量当前编码是否保留了有用的对手风格标签，不能将编码变化直接等同于理解对手。

把“替换导致的读出差向量”放大 4 倍，保持原始读出不变，策略 TV 从 0.3364% 到
1.3480%，首选改变 4/121；将差向量设为 0 则 TV 精确为 0。
这验证了测得的策略差异经过读出路径，并且幅度受限；这不是可直接部署的修复模型。
只凭这些数字也不能把原因唯一归为 LayerNorm，应包括 V 表示、输出投影、融合及策略头的
共同作用。

更广的新样本中，替换旧局内容会移动 94.35% 的非 BOS head 落点，但策略只改变
7/1953 个首选，TV 中位数 0.0468%。历史不是严格无影响；模型主要没有将它转成
稳定、有用的动作调整。

## 5. 为什么训练有历史仍会这样

以下区分源码事实和尚待因果验证的解释。

1. **主线没有启用尺度约束。** private query 未先归一化，投影后 Q/K 也没有归一化；
   当前保存权重已经处于上述饱和几何中。math SDPA 修复数值反向问题，不会自动
   把已学到的巨幅 Q/K 和近似常量读出重置成有用的检索器。
2. **next 预测不强迫选牌使用历史。** 部署代码的 next loss 直接接在公共编码上，
   系数仍是 0.1；belief/outcome/response 走各自目标。辅助预测及编码器可以继续学习，
   而最终策略对历史内容保持低敏感。这里没有证明 next loss 导致退化。
3. **奖励在 round 结束处截断。** 后一局的 PPO loss 可以学习读取前几局；但前几局
   为以后识别对手而主动试探的动作，不能直接从后几局奖励得到 GAE 信用。
   这影响跨局信息收集目标，不意味着旧 token 没有反向路径。
4. **filtered 不等于长期风格识别课程。** 当前 checkpoint 的 16 个 archive 成员为
   u194656–u195424，距 u195450 只有 26–794 updates，另有 4 个 recent 版本。
   行为筛选使用 32 个探针决策和 TV 阈值 0.05，偏好较新的版本；并未要求风格只能
   通过跨局历史识别，也未要求针对该风格有可复现收益。实际行为是否足够多样仍需
   单独测，不能只凭版本接近断言相同。

[10 月 15 日的历史权重审计](private-attention-diagnosis-2026-10-15.md)已在
u58528 等早期权重上发现严重饱和，早于记录中的大梯度爆炸窗口。
[10 月 17 日训练审计](history-training-audit-2026-10-17.md)也区分了原本的弱使用和
故障期的额外损伤。此次是 u184140/u195450 的新测量；历史证据不支持“最近 filtered
才制造了全部问题”，也不足以唯一解释最初为何形成这个优化结果。

## 6. “错配历史反而赢了”能说明什么

[上一轮完整比赛](main-matched-history-2026-11-12.md)中，匹配历史赢 113/128，
错配赢 117/128。匹配减错配的胜率差 −3.125pp，配对 95% 区间
[−8.594, +2.344]pp；净级差/局为 −0.1076，区间 [−0.2233, +0.0133]。
这两项没有确立“错配更强”。探索性的净级差/场区间确实略低于零，不能删除这个负结果，
但它还受到比赛长度差异影响，不能据此证明错误对手信息具有一般优势。

还需澄清实验名称：所谓 shuffled 是把整桌旧 token 换成另一对手对局的存档内容，
保留当前长度、round/phase 标签并按长度选 donor；包括自己的和队友的旧操作。
这不是只打乱对手身份的干净实验，可能产生不连贯的历史。四个测试对手相对 u195450
较弱，匹配组胜率已有 88.28%；不能外推到当前训练池或 DanLM。

本次结果解释了为什么改历史通常影响很小：有变化的读出在选牌中作用弱。少量概率变化
在完整比赛里仍会累积并改变后续局面，赢得更多或更少都可能发生。尚未证明那 4 场净增
胜局究竟来自随机波动、某类有害历史依赖还是 donor 分布偏差。

## 7. 下一步的验收方向（建议，未启动）

可以在隔离分支检验 Q/K 归一化及独立融合；先确认梯度、query 对局面变化的响应和
有效历史差异进入决策，再用有独立证据支持跨局决策价值的对手任务验证。最终验收应是
“正确匹配历史优于错配/无历史，且棋力没有退步”，不能只看 attention 变软或梯度非零。
当前实验没有证明任何修复已恢复对手适应能力。
