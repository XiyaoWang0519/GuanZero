## 0. 先校正两条事实（已读证据）

## 1. 对 epsilon 方案的核心判断（机制推断，未实测）

当前实现是 `w = min(1, π_old/μ)`，乘在归一化后的优势上（`history_ppo.py:392-396`）。

- **期望上几乎不改变 actor 的更新方向**。对 π(a) < 1/n 的稀有动作，w = π/μ 未被截断，该动作的期望贡献是 μ·(π/μ)·A·∇logπ = π·A·∇logπ，与纯 on-policy 相同。
- **塌缩的原因没有被触及**。稀有动作的梯度仍正比于 π(a)，epsilon 只是把"极少采到、权重 1"换成"较常采到、权重很小"，降低的是方差。
- **真正改变的是两件副作用**：状态分布变宽；回报被自己和队友后续的随机动作污染。GAE 为 γ=1、λ=0.95，接近蒙特卡洛，而掼蛋里均匀随机动作常是灾难性的（乱拆炸弹）。
- **关于 0.10**：污染的量级取决于每轮学习席位的非强制决策数，我没有查这个数。它随 epsilon 线性增长，所以 0.10 的污染是 0.02 的五倍。

结论：这套 epsilon 的负结果几乎无法解释。它既不能否定"探索不足"，也不能区分"修正抵消了探索"与"噪声伤害了回报"。我赞同砍掉 0.10，理由是污染最重，不只是预算。

更干净的小改动是分叉 rollout：随机只发生在分叉点，后续按 π 走，优势估计无污染。它本来就在下一阶段，我认为它比 epsilon 更值得投入。

## 2. 我最看重的瓶颈假设

按我的置信度排序，全部是推断：

1. **信用分配与优势估计噪声**。只有轮末奖励，全知 critic 的解释方差停在 0.55–0.65，并与熵同时变平（已验证的观察）。低熵可能是噪声优势下 PPO 过早定型的结果，而不是原因。
2. **样本量可能根本不够**。80 分钟约 930–1020 次更新，每次 32×64 步，约 200 万决策。recipe 结论"5 倍样本只 +0.1~0.2"是在每次更新行数变大的条件下得到的，不等于更长训练无效。"平台"可能只是慢斜率。
3. **自博弈分布与 B11 评估错位**。B 的辅助损失预测的是自博弈对手的响应，可能正好缓解表示学习，这与 B 有希望一致。
4. **熵本身**。平均熵 0.3–0.4 含大量选择很少的决策，未必病态。recipe Run 1 的熵系数 0.03 没有帮助（旧配方、单种子），是对熵假设的弱反证。

## 3. 今晚建议的最小实验（提议，需实测）

**三臂 × 三个全新配对种子**：

| 臂 | 内容 | 状态 |
|---|---|---|
| 1 | B 配方对照 | 已有 |
| 2 | B + epsilon 0.02 | 已实现，定位为诊断臂，不期待胜出 |
| 3 | B + 自动熵目标 | 需先实现并通过默认位级一致测试 |

如果第 3 臂今晚来不及，我建议用固定熵系数 0.03 顶替，而不是用 0.10 凑数。它零代码，并能在新配方下重测 Run 1 的结论。

**终点定义**：按固定更新数或决策数，不按墙钟秒数。T7 各臂更新数相差约 10%（928–1020），并发争抢会把系统差异混进方法比较。吞吐单独报告。

**续训还是全新种子**：主结论用全新种子。续训只适合熵臂做 20–30 分钟的便宜诊断，因为熵梯度在塌缩状态仍有作用。对 epsilon 续训，机制上预期无效：π≈1e-4 时权重约为 π·n/ε，几乎为零。

**必须加的测量**：

- 熵按合法动作数 n 和领出/跟牌分层，排除 n=1；另报 max π > 0.99 的决策占比。
- 评估同时报采样和取最大概率两种出牌方式，否则高熵臂在评估时被惩罚。
- 每个种子评估最后 2–3 个检查点取平均，降低单快照噪声。
- 预先声明检出力：种子噪声为 0.2–0.35（已验证），三种子下小于约 0.3 的效应一律记为"不确定"。

**自动熵的设计**：损失保持原始熵的均值，只让系数跟随一个标量反馈。标量用 n≥2 决策的平均熵，H/log(n) 只作分层诊断。这样不会重新加权局面。主要风险是熵被灌进无关紧要的局面（等价动作）来凑目标，所以要看熵与优势离散度的关系。
